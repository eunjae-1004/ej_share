# P-Tech 최종보고서 작성 규칙 – ChatGPT 플러그인용 통합 소스
> 이 한 파일에 [소스1 작성규칙]·[소스2 작성스타일]·[소스3 업종별예시문]·[소스4 자재관리]·[소스5 현장제어]가 모두 들어 있다.

> 프로젝트 지침에서 이 파일을 따르도록 지정한다. 보고서를 쓸 때마다 이 순서와 규칙을 그대로 적용한다.

## 작성 절차
0. [시작 안내] 사용자의 첫 메시지("시작", "안녕" 등 무엇이든)가 입력양식이 아니면, 아래 [시작 안내문]을 그대로 보여 준다. 입력양식은 복사하기 쉽게 코드블록(```)에 넣는다.
1. 사용자가 입력양식을 붙여 넣으면 교과목(자재관리 / 현장제어)을 확인하고, 해당 교과목 소스(소스4 자재관리 / 소스5 현장제어)만 사용한다. 교과목이 비어 있으면 "어느 과목인가요? 1) 자재관리 2) 현장제어"로 묻는다.
2. 필수 항목(교과목, 성명) 중 빠진 것이 있으면 한 번에 모아서 질문한다. 학과·학번·작성일이 비어 있으면 PDF에 빈칸(○○○)으로 둔다. 회사명이 비어 있으면 "○○○(주)"로 둔다.
2-1. [예시문 적용] ①~④ 중 비어 있거나 "모름·없음·잘 모르겠음"인 항목은 질문으로 멈추지 말고 아래 [소스3 업종별예시문]으로 채워 바로 진행한다.
   - 업종 고르기: 입력양식의 업종 선택 → 없으면 회사명(업종)·담당 업무로 판단 → 판단이 어려우면 "기타 제조(일반)"
   - 사례 고르기: 사용자가 고른 사례(A/B) → 없으면 학번 끝자리가 홀수면 A, 짝수면 B(학번이 없으면 A)
   - 사용자가 일부 항목(예: ①만)을 적었으면 적은 내용은 그대로 살리고, 비어 있는 항목만 그 내용과 어울리게 채운다(①과 맞지 않는 예시 문장을 억지로 넣지 않는다).
   - ⑤ 소감, ⑥ 향후 계획이 비어 있으면 교과목 학습내용과 ①~④를 바탕으로 일반적인 내용으로 쓴다.
   - 초안 맨 위에 "예시문 적용: ○○ 업종 사례 A (①②③④ 항목)"처럼 밝히고, 바로 아래에 같은 업종의 다른 사례를 한 줄로 보여 주며 "다른 사례로 바꾸려면 'B로 바꿔 주세요', 직접 쓰려면 내용을 알려 주세요"라고 안내한다.
   - 예시문은 일반적인 사례이므로 회사 고유 사실(설비명, 인원, 금액, 수치)을 덧붙이지 않는다.
3. 아래 [소스2 작성스타일]에 따라 문체·문장 길이·수준을 정한다. 초안 맨 위에 "적용 스타일: 문체 ○ / 길이 ○ / 수준 ○"을 한 줄로 밝힌다.
4. 사용자 입력과 정한 스타일로 아래 항목의 초안을 쓴다.
   ※ 아래 분량은 '최소 기준'이다. 샘플 3종([B])보다 짧게 쓰지 않는다. 한두 문장으로 끝내지 않는다.
   - Ⅰ-1-1) 개요: 3문장 내외. 소스4/5 [A]의 개요를 참고해 "이번 교육은 …" 식으로 자기 말로 다시 쓴다.
   - Ⅰ-1-3) 교육 상세내용: 학습 단위·단원 제목은 [A] 그대로 두고, 단원마다 아래 3가지를 쓴다(목차 6단계: Ⅰ. → 1. → 1) → (1) → 1-1. → 가·나·다).
     · 가. 핵심 내용 정리: 3문장 이상. [A]의 학습목표·핵심 개념을 이해한 대로 재구성한다("~라는 점을 이해하였다", "~가 핵심이었다"). 원문 문장을 그대로 옮기지 않고, 용어 나열이 아니라 '무엇을, 왜' 중심으로 쓴다.
     · 나. 실습 과정: 2문장 이상. 입력양식 "교육에서 실제로 해 본 실습"을 우선 반영하고, 언급되지 않은 실습은 "교육에서 ~ 실습을 다루었다"처럼 쓴다(실제로 수행했다고 단정하지 않는다). 측정값·결과 수치는 사용자가 말한 것만 쓴다.
     · 다. 업무 적용: 1~2문장. 사용자의 회사·담당 업무(입력양식 ①~④)와 연결해 어디에 쓸 수 있는지 쓴다.
     · 형식 예시는 소스4/5의 [C] 단원 작성 예시를 참고하되, 문장을 그대로 복사하지 않는다.
   - 요약문 3(문제해결 제안), 요약문 4(향후계획): 각 2문장 이상
   - Ⅰ-2 문제해결 경험: 5문장 이상. ① 회사 상황 → ② 문제가 드러난 계기 → ③ 교육에서 배운 내용(단원 번호 2개 이상, 예: 2-1, 3-1) → ④ 적용 방법 순서로 쓴다.
   - Ⅱ-1 문제점/차이점 도출
     · 1) 현상: 2문장 이상(무엇이 → 어떤 결과로 이어지는지)
     · 2) 원인: ①②③ 번호로 3개 이상(수준 상은 직접 원인과 근본 원인을 구분해 4개 이상)
     · 3) 개선 방안: 번호로 3개 이상(수준 중·상은 4개). 각 방안은 '방안 이름: 무엇을·어떻게 하는지' 형식으로 1~2문장
     · 4) 기대 효과: 2문장 이상. 수치는 넣지 말고 "(효과는 적용 후 확인 필요)"를 붙인다.
   - Ⅱ-2 실무와의 비교: 4문장 이상(학습모듈 방식 → 현재 회사 방식 → 차이로 생기는 문제 → 적용 시 달라지는 점)
   - Ⅲ-1 소감: 4문장 이상(배운 점, 새로 알게 된 점, 업무에 대한 생각 변화)
   - Ⅲ-2 향후 계획: '첫째, 둘째, 셋째'로 3단계 이상
4-1. [이미지 등록] 사용자가 사진·그림을 첨부했으면(없으면 이 단계 생략)
   - 최대 4장까지 사용한다. 더 많으면 내용과 가장 관련 있는 4장을 고르고 나머지는 제외했다고 알린다.
   - 각 이미지를 보고 위치와 캡션을 정한다.
     · 위치: 실습 장면·실습 화면 → "상세:단원번호"(예: 상세:2-1) / 회사 현장의 문제 모습 → "현상" / 개선 후·개선안 관련 → "개선방안" / 그 밖 → "문제해결경험"
     · 캡션: 이미지에 보이는 것만 15자 안팎으로 쓴다(예: "자재 보관 랙 현황", "PLC 입력 모듈 결선 실습"). 보이지 않는 사실이나 수치를 지어내지 않는다. 사용자가 설명을 적었으면 그 설명을 우선한다.
   - 얼굴이 크게 보이거나 회사 기밀(도면·고객사명·단가 등)이 보이면 초안에서 "이 사진은 ○○가 보여 제출 전 확인이 필요합니다"라고 알린다.
   - 초안 끝에 "그림 배치: [그림 1] 파일명 → 위치 / 캡션"을 목록으로 보여 주고, 위치·캡션을 바꿀 수 있다고 안내한다.
   - JPG·PNG가 아닌 파일(HEIC 등)이 열리지 않으면 [안내 D]를 보여 준다.
5. 초안을 채팅에 Ⅰ장(개요, 단원별 가·나·다) → 요약문 3·4 → Ⅰ-2 → Ⅱ장 → Ⅲ장 순서로 보여 주고 "고칠 부분이 있으면 말씀해 주세요. 문체·길이·수준을 바꾸고 싶으면 '음슴체로', '더 길게', '수준 상으로'처럼 말씀해 주세요. 없으면 'PDF로 만들어 주세요'라고 입력하세요."라고 묻는다.
6. 사용자가 승인하면 [PDF 생성 방법]에 따라 PDF를 만들어 내려받을 수 있게 제공한다.

## 작성 원칙
- 사용자가 학습모듈 원본 PDF를 첨부하면 내용 확인용 참고 자료로만 쓴다. 원문 문장·표를 그대로 옮기지 않고, 정리된 소스4/5 [A]의 단원 구조에 맞춰 가공해 쓴다. 첨부가 없어도 소스4/5만으로 작성한다.
- 교과목명, 요약문 1~2(주요 학습내용, 주요 기술 및 능력), 교육 프로세스, 학습 단위·단원 제목은 [A]를 그대로 쓴다. 개요와 교육 상세내용(가·나·다)은 [A]를 참고 자료로 삼아 사용자의 말로 가공해 쓴다. [A]의 문장을 통째로 옮기지 않는다.
- 샘플 3종은 문체·분량·구성만 참고한다. 샘플 문장을 그대로 옮기지 말고 반드시 사용자 회사 상황으로 쓴다.
- 사용자가 말하지 않은 수치(불량률, 금액, 시간, % 등)를 만들지 않는다. 효과는 "(적용 후 확인 필요)"처럼 쓴다.
- 사용자가 말하지 않은 회사 사실을 지어내지 않는다. 정보가 부족하면 일반적인 표현으로 쓰고 초안에서 "[확인 필요]"로 표시한다.
- 문체·길이·수준은 [소스2 작성스타일]을 따른다. 샘플 3종은 보고서체·중간·중 기준 예시이므로 문체를 따라 하지 않는다.

## PDF 생성 방법 (ChatGPT)
1. 코드 파일 찾기: 플러그인에 포함된 파일 또는 /mnt/data 의 채팅 첨부에서 「첨부_PDF생성코드」 파일을 찾아 report_pdf.py로 복사한다. 없으면 [안내 A]를 보여 준다. (코드를 새로 짜거나 고치지 않는다.)
2. 입력 JSON 작성(UTF-8): 교과목키("자재관리" 또는 "현장제어"), 작성일, 학과, 학번, 성명, 회사명, 개요(가공한 문장), 상세내용([{"제목": "(1) …", "항목": [{"소제목": "1-1. …", "정리": "…", "실습": "…", "적용": "…"}]}] – 제목·소제목은 [A]와 똑같이), 요약_문제해결, 요약_향후계획, 문제해결경험, 문제점_현상, 문제점_원인, 개선방안(리스트, 3~4개), 기대효과, 실무비교, 소감, 향후계획 (승인된 초안 문장을 그대로 넣는다)
   - 이미지가 있으면 "이미지" 키 추가: [{"파일": "/mnt/data/실제파일명", "캡션": "…", "위치": "현상"}, …]
3. 실행: python report_pdf.py 입력.json /mnt/data/최종보고서_<교과목키>_<성명>.pdf → 내려받기 링크를 준다.
4. "한글 글꼴 없음" 오류가 나면 PDF를 주지 말고 [안내 B]를 보여 준다. (ChatGPT 작업 환경에는 한글 글꼴이 없는 경우가 많다. 인터넷 설치는 시도하지 않는다.)
5. 사용자가 NanumGothic.ttf 등 한글 TTF 파일을 첨부하면 코드가 /mnt/data의 글꼴을 자동으로 찾으므로 3번을 다시 실행한다.
6. 글꼴 파일이 없거나 다시 실패하면 python-docx로 같은 구성의 Word(.docx) 파일을 만들고 [안내 C]를 보여 준다.
7. 완료 후 "PDF를 내려받아 확인하세요. 내용 수정이 필요하면 말씀해 주세요."로 마무리한다. 코드나 기술 설명은 하지 않는다.

## 처리가 안 될 때 안내문 (해당 상황에서 문구를 그대로 보여 준다)
- [안내 A – 코드 파일 없음] "보고서 PDF를 만들려면 「첨부_PDF생성코드.txt」 파일이 필요해요. 채팅창 [+] 버튼으로 첨부한 뒤 'PDF로 만들어 주세요'라고 다시 입력해 주세요."
- [안내 B – 한글 글꼴 없음] "ChatGPT에는 한글 글꼴이 없어 PDF 글자가 깨질 수 있어요. ① 강사에게 받은 'NanumGothic.ttf' 파일을 [+]로 첨부하고 'PDF로 다시 만들어 주세요'라고 입력하거나, ② 글꼴 파일이 없으면 'Word로 만들어 주세요'라고 입력하세요."
- [안내 C – Word로 대체] "PDF 대신 Word 파일로 만들었어요. 내려받아 Word에서 [파일 → 다른 이름으로 저장 → PDF]로 저장한 뒤 제출해 주세요."
- [안내 D – 사진 오류] "사진 ○번을 열 수 없어요. JPG로 저장(또는 화면 캡처)해서 다시 첨부해 주세요. 사진 없이 먼저 만들려면 '사진 빼고 만들어 주세요'라고 입력하세요."
- [안내 E – 업로드 한도] (사용자가 '파일을 올릴 수 없다'고 하면) "무료 계정은 하루에 올릴 수 있는 파일 수가 정해져 있어요. 사진을 줄이거나 내일 다시 시도해 주세요. 사진 없이도 보고서는 만들 수 있어요."

## 시작 안내문 (지침_ChatGPT.txt와 동일, 지침이 우선)

# 소스2 – 작성 스타일
※ 사용자가 쓰는 부분(Ⅰ-1 개요, Ⅰ-1-3 단원별 가·나·다, Ⅰ-2, Ⅱ·Ⅲ장, 요약문 3·4)에 적용한다. [A]를 그대로 쓰는 부분(요약문 1·2, 교육 프로세스, 제목)은 바꾸지 않는다.
■ 스타일 정하기
- 입력양식에 사용자가 고른 값을 쓴다.
- 비어 있거나 "알아서"이면 학번 끝자리(없으면 성명 글자 수)로 정해 사용자마다 다르게 한다.
  · 문체: 끝자리 0·3·6·9 → 보고서체 / 1·4·7 → 음슴체 / 2·5·8 → 설명문체
  · 길이: 끝자리 0~3 → 중간 / 4~6 → 짧게 / 7~9 → 길게
  · 수준: 기본값 중 (사용자가 고른 경우만 상·하)
■ 문체
- 보고서체: "~하였다 / ~하겠다 / ~이다" 예) 입출고 내역을 즉시 입력하도록 절차를 변경하였다.
- 음슴체(개조식): "~함 / ~임 / ~할 예정임", 문장 앞에 □·ㅇ·- 기호 사용 가능 예) 입출고 내역 즉시 입력 절차로 변경함.
- 설명문체: "~했습니다 / ~하겠습니다 / ~입니다" 예) 입출고 내역을 바로 입력하도록 절차를 바꿨습니다.
- 한 보고서 안에서는 한 가지 문체만 쓴다.
■ 문장 길이
- 짧게: 한 문장 약 30자 이내, 한 문장에 내용 하나. 문장을 짧게 나누되 항목별 최소 분량(소스1)은 지킨다.
- 중간: 한 문장 약 40~60자. 항목별 문장 수는 「소스1」 작성 절차 기준대로.
- 길게: 한 문장 약 60~90자, 원인→조치→결과를 이어 쓰는 연결형. 항목별 문장 수는 기준보다 1개 많게.
■ 수준
- 하: 쉬운 우리말 위주, 전문용어 최소(쓰면 괄호로 풀이). 원인 3개, 개선 방안 3개. 학습 단원 번호 2개 연결.
- 중: 학습모듈 용어를 적절히 사용. 원인 3개, 개선 방안 4개. 학습 단원 번호 2개 이상 연결.
- 상: 전문용어(MRP, BOM, I/O List, 교정 등)를 정확히 사용. 원인을 직접 원인/근본 원인으로 나눠 4개 이상 분석(5Why 관점). 개선 방안 4~5개, 각 방안에 "무엇을·누가·어떻게 점검" 포함. 학습 단원 번호 2~3개 연결.
- 어떤 수준이든 수치는 사용자가 준 것만 쓴다.

■ 같은 내용의 스타일별 예시 (자재관리 – 재고 불일치)
- 보고서체: 입출고 내역을 수기로 기록한 뒤 일괄 입력하여 시스템 재고와 실물 재고가 일치하지 않았다.
- 음슴체: ㅇ 입출고 내역 수기 기록 후 일괄 입력으로 시스템 재고와 실물 재고 불일치 발생함.
- 설명문체: 입출고 내역을 수기로 적은 뒤 한꺼번에 입력하다 보니 시스템 재고와 실제 재고가 맞지 않았습니다.
- 짧게: 재고가 맞지 않았다. 수기 기록이 원인이었다.
- 길게: 입출고 내역을 수기로 기록한 뒤 주 단위로 일괄 입력하면서 누락과 오기가 생겨, 시스템 재고와 실물 재고가 맞지 않고 생산 투입 시점에 자재가 부족한 일이 발생하였다.
- 수준 하(개선 방안): 1) 물건이 들어오고 나갈 때 바로 프로그램에 입력한다. 2) 한 달에 한 번 창고 재고를 직접 세어 맞춰 본다.
- 수준 상(개선 방안 일부): 1) 입출고 즉시 입력: 입출고 담당자가 입고·출고 시점에 프로그램에 등록하고, 반장이 일일 마감 때 확인한다. … 4) MRP 연계: BOM·리드타임 기준으로 발주 시점을 점검한다(학습 2-1).

- 불용자재, 폐기자재 현황을 파악할 수 있다.

### Ⅰ-1-1) 개요
자재를 추적관리하고 재고현황을 파악하여 재고를 최적으로 유지하기 위한 자재관리 프로그램을 활용할 수 있다. (선수학습: 자재 입출고 관리, 자재 창고 관리)

### Ⅰ-1-2) 교육 프로세스
- 재고 최적 관리하기: 자재관리 현황 확인 → 자재 등록 → 보관위치·보관환경 결정 → 운반설비 관리
- 자재추적 관리하기: 자재 입출고 현황 입력 → 자재적재 위치·수량 파악 → 반제품 현황 등록·파악
- 재고현황 파악하기: 재고 파악 및 관리(재고 현황·자재 회전율 분석, 불용·폐기자재 파악)

### Ⅰ-1-3) 교육 상세내용

#### (1) 재고 최적 관리하기

**1-1. 자재관리 현황 확인**
- 학습목표
  - 자재관리 프로그램으로 자재 발주 및 입출고 수량, 일정을 확인할 수 있다.
- 핵심 개념
  - 자재관리 프로그램(SCM, 공급사슬관리)은 원재료 조달부터 최종 소비자까지 공급사슬에 참여하는 모든 업체가 불필요하고 비효율적인 요소를 제거해 비용 절감과 이익 증대를 함께 달성하기 위한 프로그램이다.
  - 고객이 요구한 제품이 필요한 수량·시간·장소에 맞춰 생산 공정에 들어갈 수 있도록 하여, 고객서비스 수준을 지키면서 시스템 전체 비용을 최소화한다.
  - 도입 배경은 ① 물류 환경 변화와 원가절감 필요성, ② 정보기술 발전에 따른 정보 공유·공급망 통합, ③ 소비자 욕구 다양화, ④ 기업의 다국적화·세계화이다.
  - 자재수급계획 검토: 판매계획과 수주 품목을 기준으로 고객 납기 지연을 막고 재고 과다 보유를 억제하도록 수급량을 산출하며, 검토 결과는 자재수급계획서로 기록해 남긴다.
  - 수급수량 = 수주잔량 − 구매발주 − 생산지시 − 현재고 + 안전재고 (안전재고: 수요·리드타임·공급업체의 불확실성에 대비해 보유하는 완충재고)
- 실습 내용(수행 순서)
  1) 공급사슬관리(SCM)의 개념과 프로그램 구성을 이해한다.
  2) 발주서에 따른 품목별 수량과 일정을 프로그램에서 조회하고, 보유수량이 계획수량을 넘는 품목은 조회되지 않는 점을 확인한다.
  3) 판매계획·수주 건별 계획과 시뮬레이션 계획의 차이를 이해하고 수급수량을 산출한다.
  4) 검토 결과를 바탕으로 자재수급계획서를 작성한다.

**1-2. 자재 등록**
- 학습목표
  - 자재관리 프로그램에 부품 혹은 포장단위 명칭 및 코드를 분류 등록할 수 있다.
- 핵심 개념
  - 자재 분류란 자재를 일정한 기준에 따라 식별·구분하고, 품목마다 번호 또는 부호를 부여해 관리 목적에 맞게 체계화하는 것이다.
  - 분류 원칙: ① 점진성(앞으로 늘어날 품목을 위해 분류 범위에 여유를 둠), ② 포괄성(어떤 품목도 분류 범위 안에 들어오게 함), ③ 이해 용이성(코드만 보고 의미를 알 수 있게 함). 코드는 효율성과 편리성을 고려해 대체로 6~8자리를 사용한다.
  - 관리 목적별 분류: 수요·소모 횟수별, 성질별(내구성·소모성), 상태별(신품·중고·폐품), 용도별(사업·사무·제조용품), 계정별(원재료·반제품·제품·저장품), 가공 정도별(완제품·반제품·부품·재료)
  - 식별을 위한 번호 부여 방식: 일련번호, 블록번호(품종별 번호 범위 배정), 그룹번호(대·중·소분류), 유의숫자(치수·중량 등 수치를 그대로 기호화), 문자식, 숫자·문자 혼합식(예: B450, A2C15)
  - 취급품목 명세표에는 명칭, 규격(무게·부피·길이), 재질, 단위, 제작사·구입처·용도를 정확히 기재해 구매 시 혼동을 막는다.
- 실습 내용(수행 순서)
  1) 현재 사용하는 전체 품목 수를 파악하고, 대표 품목을 종류별로 묶어 분류 기준을 설정한다.
  2) 취급품목 명세표와 자료 카드를 작성한다.
  3) 대분류 → 중분류 → 소분류 순으로 자재 분류번호를 부여한다.
  4) 품목코드별로 자재를 자재관리 프로그램에 등록한다.

**1-3. 자재 보관위치 및 보관환경 결정**
- 학습목표
  - 자재관리 프로그램으로 자재의 보관위치 및 보관환경을 결정할 수 있다.
- 핵심 개념
  - 수입검사는 자재를 정해진 기준으로 측정·판정해 공정 투입 또는 납품 가능 여부를 결정하는 활동이다. 절차: 검사 준비·실시 → 부적합 자재 별도 보관·입출고 통제 → 검사 장비 검·교정 → 불합격 라벨 부착·시정조치 통보 → 검사 이력 데이터 관리
  - 자재별 품질정보(명칭, 규격, 재질 표기, 제작사·용도)를 확인해 혼동을 막는다.
  - 보관 원칙: ① 보관위치 표시(누구나 위치를 찾을 수 있게), ② 분류별 저장(규격·종류·재질별, 동종품은 한 장소), ③ 품질 보존(온·습도에 민감한 자재는 관리되는 장소에), ④ 선입선출(유효기간이 있는 자재는 기한이 가까운 것부터), ⑤ 공간 활용(운반 장비 이동 고려)
  - 부적합품(잉여품·불용품)은 매각·증여·해체·폐기 중 적절한 방법으로 처분하며, 검토 → 선정 → 상신 → 회람 → 관리전환 → 승인 → 처분 순서로 진행한다.
- 실습 내용(수행 순서)
  1) 입고 통보를 받으면 자재의 저장 위치와 저장 방법을 정한다(옥내: 위험물·냉장·페인트·인화물질 창고 등 / 옥외: 지면 상태와 기상 보호 고려).
  2) 자재 분류 방법, 순환 빈도, 크기, 성질, 시설 저장능력을 고려해 저장 계획을 세운다.
  3) 최대 소요 면적·부피, 재고 금액, 운반 통로를 기준으로 저장 공간을 산정한다.
  4) 품목별 보관위치와 보관환경을 프로그램에 등록하고, 부적합품을 식별해 처분 절차를 밟는다.

**1-4. 자재 운반설비 관리**
- 학습목표
  - 자재관리 프로그램으로 자재 입출고를 위한 운반설비를 결정하고 관리할 수 있다.
- 핵심 개념
  - 자재 운반의 기능은 원자재·반제품·완제품·공구·소모품을 한 위치에서 다른 위치로 옮겨 제조작업을 촉진하는 것이다.
  - 운반설비 종류: 동력식 트럭, 기중기(크레인)·산업용 모노레일·승강기, 컨베이어(경사·수평벨트·커브벨트), 무인운반차(AGV)
  - 컨베이어는 단순 운반뿐 아니라 작업대로도 쓰여 대량생산 방식의 기초가 되고, AGV는 정해진 경로로 자재를 자동 운반한다.
- 실습 내용(수행 순서)
  1) 자재 종류·특성·중량·규격을 고려해 운반설비를 결정하고, 운전원을 선정해 교육·훈련 계획을 세운다.
  2) 생산의 최적 흐름을 위해 건물·부서·생산설비의 위치를 배열한다.
  3) 설비 배치 목표(운반 시간·비용 최소화, 작업자 안전·편의, 설비투자 최소화, 공간의 경제적 이용, 배치 변경 융통성, 감독 용이)를 세우고 운반설비를 등록한다.

#### (2) 자재추적 관리하기

**2-1. 자재 입출고 현황 입력**
- 학습목표
  - 자재수급계획에 따라 자재 입고·출고 현황을 입력 관리할 수 있다.
- 핵심 개념
  - 자재소요계획(MRP)은 기준생산일정(MPS)에 따라 제품별 자재 소요량을 일정별로 구하고, 현재고·입고 예정량을 고려해 순 소요량에 대한 발주계획을 미리 세우는 절차이다.
  - 자재관리의 목적은 소요계획부터 구입의뢰·입고·출고까지의 일련의 과정을 효율적이고 합리적으로 운영하는 것이다.
  - 자재 구분: 상용자재, 예비자재, 잉여(재활용)자재, 불용자재, 기타자재, 손실·망실자재
  - 경제적 발주량(EOQ)은 구매(발주)비용과 재고유지비의 합인 총 재고비용이 최소가 되는 발주량이며, 수요 변화가 심한 경우에는 적용이 적합하지 않다.
- 실습 내용(수행 순서)
  1) 매월 말일 자재 입출고 관리대장으로 장부 재고와 실제 재고를 비교해 재고를 파악하고, 전월 수불결과 보고서를 작성한다.
  2) 월평균 사용량에서 현재고를 차감해 발주량을 결정한다(경제적·고정·기간·최적 발주량 방식 이해).
  3) 물품구매 요청서(품명·규격·수량·용도)를 작성해 구입을 의뢰하고 결재·예산 승인을 받는다.
  4) 입고검수 합격 품목을 프로그램에 등록하고 자재 입출고대장(날짜, 품명, 업체, 규격, 단위, 입고량, 출고량 등)을 작성한다.
  5) 입고 → 출고(자재불출전표 기준, 입고 순서대로) → 월말 재고조사 → 수불결과 보고서 작성의 업무 흐름을 수행한다.

**2-2. 자재적재 위치 및 수량 파악**
- 학습목표
  - 자재수급계획에 따라 자재적재 위치 및 수량을 파악할 수 있다.
- 핵심 개념
  - 자재는 형태에 따라 원자재, 부품, 반제품, 완제품, 재공품, 지급품으로 나뉜다.
  - 자재 분류는 수요 빈도, 성질, 상태, 용도, 계정별로 할 수 있으며, 분류번호는 5~7자리 정도가 효율적이다.
  - 위치 파악의 원칙: 저장 위치 표시·프로그램 등록, 종류·규격별 분류 저장, 품질 보존, 선입선출
- 실습 내용(수행 순서)
  1) 버팀목·파렛트·작업받침대를 사용해 평탄한 곳에 적재하고, 운반 중 손상을 방지하며, 옥외 적재 시 차광막 등으로 보호한다.
  2) 저장 위치를 표시하고 프로그램에 등록해 불출 요청 시 바로 찾을 수 있게 한다.
  3) 입고 시 수량을 정확히 입력하고, 불출 시 정확히 차감해 프로그램 수량을 관리한다.
  4) 정기적으로 실물 수량과 프로그램 수량을 비교·집계하고, 차이가 있으면 현 재고 기준으로 수정한 뒤 원인을 파악해 조치한다.

**2-3. 반제품 현황 등록 및 파악**
- 학습목표
  - 생산 공정 내 반제품 현황을 등록, 파악할 수 있다.
- 핵심 개념
  - 모든 자재에는 유형(완제품·원자재·반제품 등)이 부여되고, 유형에 따라 사용 가능한 코드·화면·평가 기준이 정해진다.
  - 자재 기준정보는 회사 전체가 공통으로 사용하므로 자재번호, 품목·규격, 주 저장창고를 표준화해야 한다.
  - 제품·반제품에 사용되는 조립품·부품·원자재의 구성정보(품목코드, 동일 구성 코드, 단위)도 표준화해 유지한다.
- 실습 내용(수행 순서)
  1) 일자별·기간별 입출고 현황을 조회·출력한다.
  2) 적정재고 수량을 기준으로 현재고의 과다·과소 여부를 확인한다.
  3) 창고별·프로젝트별·부서별 재고현황과 재고자산수불부를 조회해 반제품 현황을 파악한다.

#### (3) 재고현황 파악하기

**3-1. 재고 파악 및 관리**
- 학습목표
  - 창고 내 자재현황을 파악하고 주기적 재고 현황과 자재 회전율을 분석할 수 있다.
  - 불용자재, 폐기자재 현황을 파악할 수 있다.
- 핵심 개념
  - 재고는 자재·생산·물류·판매 과정에서 남아 있는 원·부자재와 상품이며, 재고의 3악은 결품 발생, 과잉재고, 재고 편재이다.
  - 과거에는 재고 보유를 자산 증대로 보았으나, 지금은 적기·적시 투입을 중시해 최소 재고를 유지하는 것을 긍정적으로 본다.
  - 재고 보유 동기: 운영(수요·공급 일치), 예방(불확실성 대비 안전재고), 투기(가격 변동 대비), 관행 등
  - 재고 관련 비용: 자재비(발주·주문처리·취급·수송비), 재고유지비(보관·재고서비스·재고위험·폐기비용, 자본비용, 감가), 재고부족비(판매기회 상실, 긴급주문, 납기지연 배상, 공정 유휴, 신용 저하)
  - 재고관리의 목적은 최적재고 유지, 고객서비스 극대화, 결품 최소화, 총비용 최소화이며, 포인트는 ABC관리, 로케이션 관리, 안전재고 설정, 경제적 발주량 확립, 재고 편재 방지, 사장재고 파악이다.
- 실습 내용(수행 순서)
  1) 재고 이동, 생산·외주 자재 출고, 생산품·외주품 입고, 재고조사, 재고조정(기초·출고조정)으로 자재 현황을 파악한다.
  2) 총 소요량, 순 소요량, 표준소요량을 계산해 자재 회전율과 장기재고를 분석한다.
  3) 표준재고(일일 최대 소요량 × 재고일수 × 리드타임)를 산정하고 관리한다.
  4) 정기·긴급 출고요청과 납입 지시를 이해하고, 불용·폐기자재 현황을 파악한다.

## [B] 샘플 보고서 3종 (사용자 작성 부분 예시, 보고서체·중간·중 기준)

### 샘플 1 – 수기 관리로 인한 재고 불일치
- 회사명: (예시) A사 – 금속가공 부품 제조
- 요약문 3. 문제해결 제안: 수기 기록으로 발생한 재고 불일치를 해결하기 위해 입출고 즉시 입력, 월말 정기 재고조사, 입출고대장 표준화, 담당자 교육을 제안하였다.
- 요약문 4. 향후계획: 입출고 즉시 입력을 팀부터 적용하고, 월말 실사 결과를 기록·분석해 관련 부서와 개선 방안을 협의하겠다.
- Ⅰ-2. 문제해결 경험: 우리 회사는 자재 입출고를 수기 장부에 적은 뒤 주 단위로 프로그램에 옮겨 입력하고 있다. 이 과정에서 기록 누락과 오기가 생겨 프로그램 재고와 창고 실물 재고가 맞지 않는 일이 반복되었다. 특히 생산 투입 직전에 자재가 부족한 것을 알게 되어 긴급 발주를 하거나, 반대로 이미 있는 자재를 다시 주문하는 경우도 있었다. 교육에서 배운 자재 입출고 현황 입력(2-1) 절차와 재고 파악 및 관리(3-1) 방법을 적용해, 입출고 즉시 입력과 월말 실사를 중심으로 개선 방법을 정리하였다. 또한 자재 입출고대장 양식을 학습모듈 기준(날짜, 품명, 규격, 단위, 입고량, 출고량)에 맞춰 다시 정리해 보았다.
- Ⅱ-1-1) 현상: 프로그램상 재고와 실제 창고 재고가 일치하지 않는다. 그 결과 생산 투입 시점에 자재가 부족해 작업이 늦어지거나, 불필요한 추가 발주가 발생하고 있다.
- Ⅱ-1-2) 원인: ① 입출고 내역을 수기로 기록한 뒤 나중에 일괄 입력하여 누락·오기가 발생한다. ② 매월 실물과 장부를 맞춰 보는 정기 재고조사(실사) 절차가 없다. ③ 담당자마다 기록 방법과 시점이 달라 기록 기준이 일정하지 않다.
- Ⅱ-1-3) 개선 방안:
  1) 입출고 즉시 입력: 입고·출고가 발생하는 시점에 담당자가 자재관리 프로그램에 바로 입력하고, 하루 업무를 마칠 때 입력 누락이 없는지 확인한다.
  2) 월말 정기 재고조사: 매월 말일 실물 재고와 프로그램 재고를 비교하고, 차이가 있으면 현 재고 기준으로 수정한 뒤 원인을 기록한다.
  3) 입출고대장 표준화: 학습모듈의 자재 입출고대장 항목에 맞춰 양식을 통일하고, 자재불출전표를 기준으로 출고를 기록한다.
  4) 담당자 교육: 입출고 담당자에게 프로그램 입력 순서와 기록 기준을 교육하고, 처음 한 달은 입력 결과를 함께 점검한다.
- Ⅱ-1-4) 기대 효과: 재고 정확도가 높아져 자재 부족으로 인한 생산 지연과 불필요한 추가 발주를 줄일 수 있다. 월말 실사 결과가 쌓이면 어떤 품목에서 차이가 자주 생기는지 파악해 관리 대상을 좁힐 수 있다. (효과의 크기는 적용 후 실사 결과로 확인 필요)
- Ⅱ-2. 실무와의 비교: 학습모듈에서는 입출고가 발생할 때마다 프로그램에 입력하고 매월 말 재고조사로 장부와 실물을 맞추도록 한다. 반면 우리 회사는 수기로 기록한 뒤 주 단위로 정리하고, 재고조사는 문제가 생겼을 때만 한다. 이 차이 때문에 기록과 실물이 맞지 않는 기간이 길어지고 원인을 찾기도 어렵다. 배운 절차를 그대로 적용하면 기록 시점의 차이를 없애고, 차이가 생겨도 한 달 안에 원인을 찾을 수 있다.
- Ⅲ-1. 소감: 자재관리 프로그램을 직접 다뤄 보며 이론으로만 알던 입출고·재고 관리 절차가 실제 업무와 어떻게 연결되는지 이해할 수 있었다. 특히 재고 기록 하나가 생산 일정과 구매 비용에 바로 영향을 준다는 점을 실감하였다. 그동안 바빠서 미루던 기록이 결국 더 큰 일을 만든다는 것을 알게 되었다. 이번 교육을 통해 자재 담당자로서 기록의 정확성이 가장 기본이라는 점을 다시 생각하게 되었다.
- Ⅲ-2. 향후 계획: 첫째, 다음 달부터 입출고 즉시 입력을 우리 팀부터 적용하겠다. 둘째, 월말 재고조사 양식을 만들어 실사 결과와 차이 원인을 기록하겠다. 셋째, 세 달 정도 결과를 모아 차이가 자주 생기는 품목을 정리하고, 관련 부서와 개선 방안을 협의하겠다.

### 샘플 2 – 자재코드 체계 미비로 인한 중복·오등록
- 회사명: (예시) B사 – 전기·전자 부품 조립
- 요약문 3. 문제해결 제안: 자재 중복·오등록 문제를 해결하기 위해 코드 체계 수립, 등록 권한 일원화, 기존 중복 코드 정리, 명세표 관리를 제안하였다.
- 요약문 4. 향후계획: 코드 체계 초안을 만들고 관련 부서와 등록 기준을 확정한 뒤, 사용 빈도가 높은 품목부터 중복 코드를 통합하겠다.
- Ⅰ-2. 문제해결 경험: 우리 회사는 같은 부품이 담당자마다 다른 이름과 코드로 등록되어, 한 품목의 재고가 여러 코드에 나뉘어 보이는 문제가 있었다. 이 때문에 창고에 재고가 있는데도 없는 줄 알고 다시 주문하거나, 비슷한 이름의 다른 부품이 출고되는 일이 있었다. 교육에서 배운 자재 분류 원칙(1-2)과 자재번호 부여방식(2-2)을 바탕으로 코드 체계를 정비하는 방안을 정리하였다. 또한 반제품 현황 등록(2-3)에서 배운 기준정보 표준화(자재번호, 품목·규격, 주 저장창고) 개념을 함께 적용하였다.
- Ⅱ-1-1) 현상: 동일 부품이 서로 다른 품명·코드로 중복 등록되어 재고 현황이 정확하지 않다. 그 결과 중복 발주와 잘못된 품목 출고가 발생하고 있다.
- Ⅱ-1-2) 원인: ① 자재 분류 기준과 코드 부여 규칙이 문서로 정해져 있지 않다. ② 신규 자재를 누구나 임의로 등록할 수 있다. ③ 품목명, 규격, 단위 같은 기준정보 입력 방식이 통일되어 있지 않다.
- Ⅱ-1-3) 개선 방안:
  1) 코드 체계 수립: 분류 원칙(점진성·포괄성·이해 용이성)에 맞춰 대분류-중분류-일련번호 형식의 그룹 번호 체계를 정하고, 앞으로 늘어날 품목을 위한 여유 번호를 둔다.
  2) 등록 권한 일원화: 신규 자재 등록 담당자를 지정하고, 등록 시 품목명·규격·재질·단위를 필수로 입력하게 한다.
  3) 기존 코드 정리: 현재 등록된 품목을 점검해 같은 부품의 중복 코드를 하나로 통합하고, 사용하지 않는 코드는 사용 중지로 처리한다.
  4) 명세표 관리: 학습모듈의 취급품목 명세표 항목에 따라 품목별 기준정보를 정리해 공유한다.
- Ⅱ-1-4) 기대 효과: 한 품목의 재고를 하나의 코드로 정확히 볼 수 있어 중복 발주와 오출고를 줄일 수 있다. 신규 품목도 같은 규칙으로 등록되어 담당자가 바뀌어도 관리 기준이 유지된다. (중복 코드 수와 개선 효과는 점검 후 확인 필요)
- Ⅱ-2. 실무와의 비교: 학습모듈에서는 분류 기준을 먼저 정하고 명세표를 만든 뒤 대·중·소분류 순으로 번호를 부여하도록 한다. 우리 회사는 이런 기준 없이 필요할 때마다 담당자가 이름을 붙여 등록하고 있다. 그래서 같은 부품도 사람마다 다르게 부르고, 프로그램에서도 따로 관리된다. 배운 절차를 적용하면 등록 단계에서부터 오류를 막을 수 있다.
- Ⅲ-1. 소감: 자재 코드가 단순한 번호가 아니라 재고 정확도와 업무 효율을 좌우하는 기준 정보라는 것을 알게 되었다. 여러 번호 부여 방식을 비교해 보면서 우리 회사에 맞는 방식을 고르는 것이 중요하다고 느꼈다. 작은 규칙 하나가 여러 부서의 업무를 편하게 만든다는 점이 인상 깊었다. 앞으로 기준을 먼저 세우고 일하는 습관을 갖고 싶다.
- Ⅲ-2. 향후 계획: 첫째, 우리 부서 자재 목록을 정리해 코드 체계 초안을 만들겠다. 둘째, 구매·생산 부서와 협의해 신규 등록 기준을 확정하고 등록 담당자를 정하겠다. 셋째, 사용 빈도가 높은 품목부터 중복 코드를 통합하겠다.

### 샘플 3 – 보관위치 미지정으로 인한 선입선출 실패·자재 탐색 지연
- 회사명: (예시) C사 – 식품 포장재 생산
- 요약문 3. 문제해결 제안: 보관위치 미지정으로 인한 탐색 지연과 선입선출 실패를 해결하기 위해 로케이션 부여, 위치·환경 등록, 선입선출 배치, 정기 점검을 제안하였다.
- 요약문 4. 향후계획: 사용 빈도가 높은 구역부터 로케이션 표시와 선입선출 배치를 적용하고, 불용 자재를 매월 점검하겠다.
- Ⅰ-2. 문제해결 경험: 우리 회사 창고는 자재 보관위치가 정해져 있지 않아 빈 공간에 그때그때 자재를 쌓아 두고 있다. 그래서 출고할 때 자재를 찾는 데 시간이 걸리고, 먼저 들어온 포장재가 안쪽에 남아 유효기간이 지나는 일이 있었다. 교육에서 배운 보관위치·보관환경 결정(1-3)과 자재적재 위치 및 수량 파악(2-2)을 적용해 로케이션 관리 방안을 정리하였다. 특히 보관 원칙 중 위치 표시, 분류별 저장, 선입선출을 우리 창고에 맞게 적용하는 방법을 검토하였다.
- Ⅱ-1-1) 현상: 출고 시 자재를 찾는 시간이 길다. 또한 선입선출이 지켜지지 않아 유효기간이 지난 포장재가 발생하고 있다.
- Ⅱ-1-2) 원인: ① 보관위치(로케이션)가 지정·표시되어 있지 않다. ② 자재에 입고일자가 표시되지 않아 먼저 들어온 자재를 구분하기 어렵다. ③ 프로그램에 보관위치 정보가 등록되어 있지 않아 위치를 담당자 기억에 의존한다.
- Ⅱ-1-3) 개선 방안:
  1) 로케이션 부여: 창고를 구역·랙·단으로 나누어 위치 번호를 부여하고 현장에 표시한다.
  2) 위치·환경 등록: 품목별 보관위치와 보관환경(온도·습도 등)을 프로그램에 등록하고, 입고할 때 위치를 함께 입력한다.
  3) 선입선출 배치: 입고일자 라벨을 붙이고 먼저 들어온 자재를 꺼내기 쉬운 앞쪽에 배치한다. 유효기간이 있는 자재는 기한이 가까운 것부터 출고한다.
  4) 정기 점검: 매월 위치별 실물과 프로그램 정보를 대조하고, 장기 보관 자재와 불용 자재를 따로 파악한다.
- Ⅱ-1-4) 기대 효과: 자재를 찾는 시간이 줄고, 선입선출이 지켜져 유효기간 경과로 인한 폐기가 줄어든다. 담당자가 바뀌어도 위치 정보로 같은 수준의 관리를 유지할 수 있다. (탐색 시간과 폐기 감소량은 적용 전후 측정 필요)
- Ⅱ-2. 실무와의 비교: 학습모듈에서는 보관위치를 표시하고 프로그램에 등록하며, 분류별로 저장하고 선입선출을 지키도록 한다. 우리 회사는 위치를 정하지 않고 빈 공간에 보관하며, 위치는 담당자 기억에 의존한다. 이 때문에 담당자가 없을 때는 자재를 찾지 못하는 경우도 있다. 배운 원칙을 적용하면 누구나 같은 방법으로 자재를 찾고 관리할 수 있다.
- Ⅲ-1. 소감: 보관위치와 보관환경을 체계적으로 정하는 것만으로도 재고 손실과 작업 시간을 줄일 수 있다는 점이 인상 깊었다. 적재 방법과 저장 공간 산정까지 배우면서 창고도 계획이 필요한 공간이라는 것을 알게 되었다. 지금까지 당연하게 여기던 방식을 다시 보게 되었다. 작은 것부터 바꿔 보고 싶다는 생각이 들었다.
- Ⅲ-2. 향후 계획: 첫째, 사용 빈도가 높은 구역부터 로케이션 번호를 표시하겠다. 둘째, 입고일자 라벨 부착을 시작하고 선입선출 배치로 바꾸겠다. 셋째, 매월 불용·장기 보관 자재 현황을 정리해 처분 여부를 상사와 협의하겠다.

## [C] Ⅰ장 단원 작성 예시 (가공 방식 참고용, 보고서체·중간·중 기준)
> 문장을 그대로 복사하지 말고, 사용자의 문체·수준과 회사 상황에 맞게 다시 쓴다.

#### (1) 재고 최적 관리하기

**1-1. 자재관리 현황 확인**
- 가. 핵심 내용 정리: 자재관리 프로그램은 원자재 조달부터 고객 납품까지 공급사슬 전체의 흐름을 한 화면에서 관리하도록 돕는 도구라는 점을 이해하였다. 특히 판매계획과 수주 정보를 기준으로 수급수량을 계산해, 납기를 지키면서도 재고를 너무 많이 들고 있지 않도록 균형을 잡는 것이 핵심이었다. 수급수량은 수주잔량에서 이미 발주했거나 생산 지시한 수량과 현재고를 빼고 안전재고를 더해 구한다는 원리도 정리하였다.
- 나. 실습 과정: 발주서에 따른 품목별 수량과 일정을 프로그램에서 조회하고, 판매계획 기준과 수주 기준 계획의 차이를 비교해 보았다. 검토 결과를 자재수급계획서 양식에 정리하는 과정까지 실습하였다.
- 다. 업무 적용: 현장에서 긴급 발주가 생기는 품목을 수급수량 기준으로 다시 점검하면, 납기 지연과 과다 재고를 함께 줄이는 데 활용할 수 있다.

**1-2. 자재 등록**
- 가. 핵심 내용 정리: 자재 분류는 단순히 이름을 붙이는 일이 아니라, 누구나 같은 기준으로 자재를 식별하도록 번호 체계를 만드는 일이라는 것을 배웠다. 좋은 분류 체계는 앞으로 늘어날 품목을 받아들일 여유가 있고, 모든 품목을 빠짐없이 담으며, 코드만 보고도 의미를 알 수 있어야 한다. 번호를 붙이는 방식에는 일련번호, 블록번호, 대·중·소분류의 그룹번호, 치수 등을 담는 유의숫자 방식 등이 있어 목적에 맞게 골라야 한다.
- 나. 실습 과정: 실습 자재의 품목 수를 파악해 분류 기준을 정하고, 품목 명세표에 명칭·규격·재질·단위를 정리하였다. 이어서 대분류부터 소분류 순으로 번호를 부여해 프로그램에 등록해 보았다.
- 다. 업무 적용: 같은 부품이 여러 이름으로 등록되는 현장 문제를 막으려면, 등록 전에 분류 기준과 명세표 작성 규칙부터 정해야 한다는 점을 업무에 적용할 수 있다.

**1-3. 자재 보관위치 및 보관환경 결정**
- 가. 핵심 내용 정리: 자재는 입고 단계의 수입검사로 사용 가능 여부를 먼저 판정하고, 부적합품은 따로 보관해 섞이지 않게 해야 한다는 점을 이해하였다. 보관할 때는 위치 표시, 종류·규격별 분류 저장, 품질 보존, 선입선출, 공간 활용의 원칙을 함께 지켜야 자재를 빨리 찾고 손실을 줄일 수 있다. 또한 쓰지 않는 잉여품과 불용품은 검토·승인 절차를 거쳐 매각·해체·폐기 등으로 처분해야 보관 비용을 줄일 수 있다는 것도 정리하였다.
- 나. 실습 과정: 입고된 자재의 저장 장소를 옥내·옥외 조건에 맞게 정하고, 자재 크기와 순환 빈도를 고려해 저장 공간을 계획하였다. 정한 보관위치와 보관환경을 프로그램에 등록하는 과정을 실습하였다.
- 다. 업무 적용: 창고에 보관위치 번호와 입고일자 표시를 도입하면 자재를 찾는 시간을 줄이고 선입선출을 지키는 데 바로 활용할 수 있다.

**1-4. 자재 운반설비 관리**
- 가. 핵심 내용 정리: 자재 운반은 원자재부터 완제품까지를 필요한 곳으로 옮겨 생산 흐름을 끊기지 않게 하는 기능이라는 점을 배웠다. 운반설비에는 동력식 트럭, 크레인·모노레일·승강기, 컨베이어, 무인운반차(AGV) 등이 있으며, 자재의 무게·크기·이동 경로에 따라 알맞은 설비가 달라진다. 설비 배치는 운반 시간과 비용을 줄이고 작업자 안전을 지키는 방향으로 계획해야 한다.
- 나. 실습 과정: 실습 자재의 특성을 기준으로 운반설비를 선정하고, 설비 배치 목표를 정리해 프로그램에 운반설비 정보를 등록하였다.
- 다. 업무 적용: 현장의 운반 동선을 점검해 불필요한 이동을 줄이고, 운반 장비 운전자 교육 계획을 세우는 데 활용할 수 있다.

#### (2) 자재추적 관리하기

**2-1. 자재 입출고 현황 입력**
- 가. 핵심 내용 정리: 자재소요계획(MRP)은 생산 일정을 기준으로 필요한 자재의 양과 시점을 미리 계산해 발주 계획을 세우는 방법이라는 점을 이해하였다. 자재관리의 목적은 소요계획부터 구매 의뢰, 입고, 출고까지를 하나의 흐름으로 합리적으로 운영하는 데 있다. 발주량은 월평균 사용량과 현재고를 바탕으로 정하며, 경제적 발주량(EOQ)처럼 총 재고비용을 최소로 하는 방법도 있다는 것을 배웠다.
- 나. 실습 과정: 월말 재고를 장부와 실물로 비교해 파악하고, 발주량 결정과 물품 구매 요청서 작성, 입고검수 후 등록, 자재 입출고대장 작성까지의 흐름을 따라 실습하였다.
- 다. 업무 적용: 입출고를 발생 즉시 기록하고 월말에 실물과 맞춰 보는 절차를 도입하면 재고 불일치 문제를 줄이는 데 활용할 수 있다.

**2-2. 자재적재 위치 및 수량 파악**
- 가. 핵심 내용 정리: 자재는 원자재, 부품, 반제품, 완제품, 재공품 등 형태에 따라 나뉘며, 위치와 수량을 정확히 알려면 분류 저장과 위치 표시가 먼저라는 점을 배웠다. 적재할 때는 파렛트나 버팀목으로 바닥과 띄우고 손상을 막아야 하며, 선입선출이 되도록 배치해야 한다. 수량은 입고할 때 정확히 입력하고 출고할 때 정확히 차감해야 프로그램과 실물이 일치한다.
- 나. 실습 과정: 자재를 안전하게 적재하고 저장 위치를 표시해 프로그램에 등록한 뒤, 정해진 기간마다 실물 수량과 프로그램 수량을 비교해 차이를 조정하는 과정을 실습하였다.
- 다. 업무 적용: 정기적으로 실물과 프로그램 수량을 대조하고 차이 원인을 기록하면, 같은 문제가 반복되는 품목을 찾아 관리하는 데 활용할 수 있다.

**2-3. 반제품 현황 등록 및 파악**
- 가. 핵심 내용 정리: 반제품을 포함한 모든 자재에는 유형이 지정되고, 그 유형에 따라 사용하는 코드와 관리 방식이 정해진다는 점을 이해하였다. 자재번호, 품목·규격, 주 저장창고 같은 기준정보는 회사 전체가 함께 쓰기 때문에 표준화되어 있어야 부서 간 혼선이 생기지 않는다.
- 나. 실습 과정: 기간별 입출고 현황과 창고별·부서별 재고 현황을 조회해, 적정재고 대비 과다·과소 품목을 확인하는 실습을 하였다.
- 다. 업무 적용: 공정 중간에 쌓이는 반제품을 기준정보에 맞춰 등록하면 현장 재고와 생산 진행 상황을 함께 파악하는 데 활용할 수 있다.

#### (3) 재고현황 파악하기

**3-1. 재고 파악 및 관리**
- 가. 핵심 내용 정리: 재고는 많을수록 좋은 것이 아니라 결품, 과잉재고, 재고 편재라는 세 가지 문제를 함께 관리해야 하는 대상이라는 점을 배웠다. 재고를 가지는 데에는 보관·자본·위험 비용이, 재고가 부족하면 판매 기회 손실과 긴급 주문 비용이 생기므로 둘 사이의 균형이 중요하다. 재고관리는 ABC 관리, 위치 관리, 안전재고 설정, 사장재고 파악 같은 방법으로 최적 수준을 유지하는 활동이다.
- 나. 실습 과정: 재고 이동, 입출고, 재고조사와 조정으로 자재 현황을 파악하고, 소요량과 표준재고를 계산해 회전율과 장기재고를 분석하였다. 불용·폐기 자재 현황을 정리하는 과정도 실습하였다.
- 다. 업무 적용: 장기 보관 중인 자재를 정기적으로 찾아 처분 여부를 검토하면 창고 공간과 재고 비용을 줄이는 데 활용할 수 있다.

### Ⅰ-1-1) 개요
현장 제어기기의 특성을 파악하여 설정함으로써 제어대상 설비를 안정적으로 운용할 수 있다. (선수학습: PLC, 자동제어 및 시퀀스제어, 센서공학 기본 지식, 공정배관계장도, 디지털공학, 규격집(KSC·ISO·IEC), 계측장비)

### Ⅰ-1-2) 교육 프로세스

- 구동기 운영하기: 구동기 동작과 활용 → 구동기 회로구성과 조치

### Ⅰ-1-3) 교육 상세내용

#### (1) 현장계측기 운영하기

**1-1. 공정변수와 온도 및 압력 검출방법**
- 학습목표
  - 공정변수(Process Variable)를 나열할 수 있고, 그 의미와 특성을 확인하여 운용에 활용할 수 있다.
  - 온도 검출 방법과 신호 전송기에 대한 원리를 확인하여 정확한 제어 운영을 할 수 있다.
  - 압력 검출 방법과 신호 전송기에 대한 원리를 확인하여 정확한 제어 운영을 할 수 있다.
- 핵심 개념
  - 공정변수는 공정의 조작 상태나 물리적 상태를 바꾸는 환경 조건으로, 물질의 온도·압력·농도·유속 등을 말한다.
  - 검출한 물리량은 그대로 비교·전송하기 어려워 다루기 쉬운 계장용 신호로 바꾼다. 검출기는 물리량을 힘·변위·전압·저항으로 1차 변환하고, 전송기는 여기에 보조 에너지를 더해 공기압·전압·전류 신호로 만든다. 둘을 합친 장치를 변환기라 한다.
  - 계장용 신호 범위(0~100%): 공기압 0.2~1.0kgf/cm², 전압 1~5VDC, 전류 4~20mADC
  - 센서는 측정 대상에 따라 물리센서(온도·광·자기 등), 역학센서(길이·변위·압력·속도 등), 화학센서(가스·습도 등)로 나뉜다.
  - 센서 선정 시 검출 범위, 감도, 응답속도, 정밀도, 신뢰성(내환경성·수명), 보수성, 생산성을 고려한다.
- 실습 내용(수행 순서)
  1) 디지털멀티미터로 서미스터(10kΩ)의 온도별 저항값(0℃·25℃·36℃·100℃)을 측정해 기준값과 비교한다.
  2) 서미스터의 온도 변화를 전압 출력으로 바꾸는 회로를 구성하고, 온도별 출력 전압을 기록해 그래프로 직선성을 확인한다.
  3) 서미스터 정전류(1mA) 부하 특성을 실험한다.
  4) 로드셀(휘트스톤 브리지 구조)과 차동증폭기로 압력(하중) 센서 회로를 구성하고, 무부하·하중 인가 시 출력 전압 변화를 확인한다. 전압 폴로어를 사용하는 이유(부하 임피던스 영향 방지)를 이해한다.

**1-2. 유량, 액위 및 진동 검출 방법**
- 학습목표
  - 유량 검출 방법과 신호 전송기에 대한 원리를 확인하여 정확한 제어 운영을 할 수 있다.
  - 액위 검출 방법과 신호 전송기에 대한 원리를 확인하여 정확한 제어 운영을 할 수 있다.
  - 진동 검출 방법과 신호 전송기에 대한 원리를 확인하여 정확한 제어 운영을 할 수 있다.
- 핵심 개념
  - 유량은 단위 시간에 임의의 단면을 통과하는 유체의 질량이나 부피로, 밀도가 변하는 유체는 부피보다 질량 측정이 바람직하다.
  - 액위 검출에는 유리관식·플로트로 직접 재는 직접 방법과, 탱크 바닥 압력·방사선 투과율·전파 속도·전도율 등으로 재는 간접 방법이 있다.
  - 진동 검출에는 무게와 평형시키는 방법, 스프링 변위를 이용하는 방법, 압력에 따른 변화를 이용하는 방법(압전형) 등이 있다.
- 실습 내용(수행 순서)
  1) 결로 센서와 트랜지스터 발진 회로로 액위 검출 회로를 구성하고, 액위가 검출되면 부저가 동작하는지 확인한다.
  2) 압전형 진동센서에 발진기와 오실로스코프를 연결하고, 2kHz 전후에서 출력이 최대가 되는 공진 주파수를 찾는다.
  3) 출력이 1/2로 줄어드는 아래쪽·위쪽 차단 주파수를 확인한다.

#### (2) 입출력장치 운영하기

**2-1. 기본적인 운영 및 제어기기 결선**
- 학습목표
  - 입출력장치 매뉴얼에 의하여 제어기기와 시스템 활용에 대한 기본적인 운영을 할 수 있다.
  - 입출력목록(I/O List)에 의해서 제어기기와 시스템 활용에 필요한 현장기기와 결선에 대한 정보를 확인할 수 있다.
- 핵심 개념
  - 디지털 입력은 전류 싱크/소스 형식을 모두 지원하며, 기본 입력 규격은 정격 DC 24V·7mA, 포토커플러 절연이다(LS산전 사용설명서 기준).
  - 디지털 출력(릴레이)은 DC 24V/2A, AC 220V/2A 정격이며, 코일 부하를 구동할 때는 개폐 빈도와 릴레이 수명을 고려해야 한다.
  - 입력 배선은 DC 12V/24V, 출력 배선은 AC 110V/220V 또는 DC 5V/24V로 선택해 결선한다.
  - I/O List는 제어기기와 현장기기 사이의 결선 정보를 정리한 목록으로, 결선·점검의 기준이 된다.
- 실습 내용(수행 순서)
  1) DC 입력부에 DC 출력형 외부기기(센서 등)를 접속한다. 입력용 전원과 센서용 전원은 같은 전원을 사용한다.
  2) NPN 트랜지스터 출력 회로를 구성한다.
  3) PNP 트랜지스터 출력 회로를 구성한다. 결선을 잘못하면 TR 소자가 파손될 수 있으므로 반드시 확인한다.

**2-2. 기본적인 구성과 정상상태의 이해**
- 학습목표
  - 해당 입출력장치 도면 및 규격서에 의하여 입출력장치와 구성을 파악할 수 있다.
  - 입출력장치(I/O 모듈, 카드)의 구성을 파악하여 정상상태 여부를 판단할 수 있다.
- 핵심 개념
  - 기본 유닛은 CPU 상태표시 LED, 입출력 LED, RS-485 통신 단자대, 모드 설정 키 스위치, RS-232C 커넥터, 확장 커넥터 등으로 구성된다.
  - 증설 모듈은 입력·출력 LED, 입출력 접점과 코먼 단자, 증설 케이블로 구성된다.
  - 운전 모드: RUN(프로그램 연산 실행), STOP(정지), PAUSE(일시 정지), REMOTE(리모트 운전)
- 실습 내용(수행 순서)
  1) PWR LED(전원 상태), RUN LED(운전 상태), ERR LED(자기진단 에러 시 점멸)로 CPU 상태를 확인한다.
  2) 입출력 단자의 접점 상태, 통신 단자와 운전 모드 설정 상태를 확인한다.
  3) 모듈 장착: 고정용 돌기를 베이스 홀에 넣고 밀착한 뒤 나사로 고정하고, 확실히 장착되었는지 확인한다.
  4) 모듈 분리: 고정 나사를 푼 뒤 들어 올려 분리한다. 무리한 장착·분리는 모듈 파손의 원인이 된다.

#### (3) 전송기 운영하기

**3-1. 전송기의 동작과 검사**
- 학습목표
  - 전송기 매뉴얼에 의해 기기 동작 활용에 필요한 기술을 갖출 수 있다.
  - 전송기 동작상태 검사를 할 수 있는 기술을 갖출 수 있다.
- 핵심 개념
  - 데이터 전송기는 USB로 전원을 공급받고, 아날로그 입력 8채널(±10V)과 디지털 입출력(이벤트 마커, 원격 시작/정지, 비율·카운터 입력)을 갖춘다.
  - 신호 리드선은 단자에 넣고 나사로 절연 피복 부분을 조여 고정하며, 지나치게 조이면 나사가 파손될 수 있다.
  - NI 9215 아날로그 입력 모듈(동시 샘플 4채널)과 CompactDAQ USB 섀시로 연속 파형 측정을 할 수 있다.
  - USBISP는 AVR 계열 마이크로컨트롤러에 펌웨어를 다운로드·검사하는 장치이다.
- 실습 내용(수행 순서)
  1) 전송기 소프트웨어를 설치한다. 설치가 끝날 때까지 USB 케이블을 연결하지 않는다.
  2) 하드웨어 매니저에서 장치 목록과 펌웨어 업데이트 상태를 확인한다.
  3) 입력 신호를 연결하고 데이터가 실시간으로 표시·전송되는지 확인해 동작상태를 검사한다.

**3-2. 전송기 회로구성과 조치**
- 학습목표
  - 전송기 회로구성 도면을 파악하고 정상 동작 여부를 감시할 수 있다.
  - 전송기 교정 절차를 파악하여 필요시 조치할 수 있다.
- 핵심 개념
  - USB-UART 핀 구성은 1 VCC, 2 RXD(PC 수신), 3 TXD(PC 송신), 4 GND이며, ISP 커넥터와 UART 커넥터를 동시에 연결하면 데이터선이 합선될 수 있다.
  - USB 전원은 규격상 500mA까지 가능하지만 100mA 이내 사용을 권장하며, 모터처럼 전류가 큰 부하는 외부 전원을 쓴다.
- 실습 내용(수행 순서)
  1) LED 상태로 동작을 판단한다: 다운로딩 중 빨간 LED, 완료 시 녹색 LED, 정상 연결 시 녹색 점멸, 타깃 미연결 시 빨간 점멸, 다운로드 에러 시 두 LED 동시 점멸
  2) USB 전원 사용 DIP 스위치를 OFF하고, 모터 구동용 외부 전원(파워 서플라이)을 따로 공급해 전원을 분리한다.

#### (4) 구동기 운영하기

**4-1. 구동기의 동작과 활용**
- 학습목표
  - 컨트롤 밸브 매뉴얼에 의해 기기 동작 활용에 필요한 기술을 갖출 수 있다.
  - 액추에이터 매뉴얼에 의해 기기 동작 활용에 필요한 기술을 갖출 수 있다.
- 핵심 개념
  - 솔레노이드는 코일에 전류가 흐르면 고정철심과 가동철심 사이에 흡인력이 생기며, AC 전원은 스트로크가 클수록 전류가 커져 장시간 통전 시 코일이 소손될 수 있다(DC는 전류 일정).
  - AC 솔레노이드의 쉐이딩 링은 흡인력 맥동에 의한 소음을 막으며, 빠지면 소음이 발생한다.
  - 코일 절연 종류별 온도 상승 한도: E종 80℃, B종 90℃, F종 115℃, H종 140℃ 이하. 공기압용 전자밸브는 보통 E·B종을 쓴다.
  - 전자밸브의 기본 특성: 응답시간, 허용 전압 변동(정격의 ±10% 이내), 복귀 전압, 절연 저항(1MΩ 이상), 내전압
  - 단동 실린더는 한 방향만 공기압으로 움직이고 스프링 등으로 복귀하며, 복동 실린더는 전·후진 양방향으로 추력을 내고 속도 제어성이 좋다.
  - 특수 실린더: 양로드, 탠덤(같은 지름에서 약 2배 출력), 듀얼 행정(정지 위치 2곳), 로킹(임의 위치 정지)
- 실습 내용(수행 순서)
  1) 용도에 맞는 방향제어밸브(포트 수, 직동식·파이로트식)를 구성한다.
  2) 실린더의 충격 흡수 원리를 이해한다: 소형은 러버 버퍼, 대형은 에어쿠션으로 스트로크 끝에서 감속하며, 하중이 크고 속도가 빠르면 외부 쇼크 업소버를 사용한다.

**4-2. 구동기 회로구성과 조치**
- 학습목표
  - 구동기의 회로구성 도면을 파악하고 정상 동작 여부를 감시할 수 있다.
  - 간단한 교정 절차를 파악하여 필요시 조치할 수 있다.
- 핵심 개념
  - 선택 스위치로 수동(MAN)과 자동(AUT)을 고른다. 수동은 각 작업 요소를 개별 푸시버튼으로 움직이며, 점검·조정을 위해 반드시 필요하다.
  - 자동에는 시작 스위치를 누를 때 한 번만 동작하는 단속 작업과, 정지 신호 전까지 계속 동작하는 연속 작업이 있다.
  - 단속·연속이 모두 필요하면 두 조건을 병렬로 연결해 구성한다.
- 실습 내용(수행 순서)
  1) 자기유지 회로를 이용한 자동 연속 회로의 동작(S3로 시작, 잠금 해제 시까지 연속)을 확인한다.
  2) 단속용 스위치(S3)와 연속용 스위치(S4)를 병렬로 연결한 자동 연속/단속 회로로 수정한다.
  3) 수정한 회로가 도면대로 동작하는지 확인한다.

## [B] 샘플 보고서 3종 (사용자 작성 부분 예시, 보고서체·중간·중 기준)

### 샘플 1 – 온도·압력 센서 측정값 오차
- 회사명: (예시) D사 – 사출 성형
- 요약문 3. 문제해결 제안: 센서 측정 오차로 인한 불량을 줄이기 위해 교정 주기 설정, 점검표 보완, 허용 오차 기준 수립, 교정 이력 관리를 제안하였다.
- 요약문 4. 향후계획: 담당 설비의 센서 목록과 교정 주기·점검표를 만들어 적용하고, 교정 이력을 기록해 개선을 건의하겠다.
- Ⅰ-2. 문제해결 경험: 우리 회사 사출 설비는 온도 컨트롤러의 표시값과 휴대용 측정기로 잰 금형 온도가 다를 때가 있어, 성형 조건이 맞지 않아 불량이 생기는 경우가 있었다. 교육에서 배운 공정변수와 온도·압력 검출방법(1-1)을 통해 검출기와 전송기, 계장용 신호(4~20mA 등)의 원리를 이해하게 되었다. 서미스터 특성 실험에서 온도에 따라 저항과 출력 전압이 어떻게 변하는지 직접 확인하면서, 센서 상태가 측정값에 큰 영향을 준다는 것을 알았다. 이를 바탕으로 전송기 교정 절차(3-2)를 참고해 센서 점검·교정 방법을 정리하였다.
- Ⅱ-1-1) 현상: 온도 컨트롤러 표시값과 기준 측정기로 잰 값이 서로 다르다. 그 결과 성형 조건이 기준에서 벗어나 불량이 발생하고 있다.
- Ⅱ-1-2) 원인: ① 센서와 전송기의 정기 교정 기준이 없다. ② 센서 설치 위치와 배선 상태를 정기적으로 점검하지 않는다. ③ 측정값이 이상한지 판단하는 허용 오차 기준이 없다.
- Ⅱ-1-3) 개선 방안:
  1) 교정 주기 설정: 설비별 센서·전송기 목록을 만들고 교정 주기와 교정 절차를 매뉴얼로 정한다.
  2) 점검표 보완: 설비 점검표에 센서 설치 상태, 배선 상태, 표시값과 기준값 비교 항목을 추가해 작업 시작 전에 확인한다.
  3) 허용 오차 기준: 설비 사양을 확인해 허용 오차를 정하고, 벗어나면 즉시 교정하거나 교체하도록 한다.
  4) 이력 관리: 교정·교체 결과를 기록해 자주 문제가 생기는 센서를 파악한다.
- Ⅱ-1-4) 기대 효과: 측정 오차로 인한 성형 조건 이탈과 불량을 줄이고, 설비 이상을 미리 발견할 수 있다. 교정 이력이 쌓이면 센서 교체 시기를 예측할 수 있다. (허용 오차 값과 불량 감소 효과는 설비 사양 확인과 적용 후 확인 필요)
- Ⅱ-2. 실무와의 비교: 학습모듈에서는 측정 전에 계측기의 특성을 확인하고, 교정 절차에 따라 정상 동작 여부를 감시하도록 한다. 반면 우리 회사는 센서에 이상이 생긴 뒤에야 교체하는 사후 대응 방식이다. 이 때문에 이상을 알아차리기 전까지 불량이 이어질 수 있다. 점검표에 교정 항목을 넣으면 예방 중심으로 관리할 수 있다.
- Ⅲ-1. 소감: 서미스터와 로드셀 실험을 통해 센서 출력이 어떻게 전기 신호로 바뀌는지 직접 확인할 수 있었다. 그동안 표시값을 그대로 믿고 작업했는데, 측정값도 점검과 교정이 필요하다는 것을 알게 되었다. 계장용 신호의 원리를 이해하니 설비 매뉴얼도 더 잘 읽히게 되었다. 현장에서 바로 활용할 수 있는 내용이라 의미가 컸다.
- Ⅲ-2. 향후 계획: 첫째, 담당 설비의 센서·전송기 목록을 정리하겠다. 둘째, 교정 주기와 점검표 항목을 만들어 작업 시작 전 점검에 적용하겠다. 셋째, 교정 이력을 기록해 반복 문제가 있는 센서를 상사에게 보고하고 개선을 건의하겠다.

### 샘플 2 – PLC 입출력 결선 오류·모듈 상태 점검 미흡
- 회사명: (예시) E사 – 자동화 조립 라인
- 요약문 3. 문제해결 제안: PLC 입력 신호 이상 문제를 해결하기 위해 도면 갱신 규칙, 센서 교체 체크리스트, 점검 순서 표준화, 모듈 취급 교육을 제안하였다.
- 요약문 4. 향후계획: 담당 라인의 I/O List를 최신화하고 점검 흐름도와 체크리스트를 공유한 뒤, 고장 기록을 분석하겠다.
- Ⅰ-2. 문제해결 경험: 우리 회사 조립 라인에서 설비 개조 후 센서는 동작하는데 PLC에 입력 신호가 들어오지 않아 라인이 멈춘 적이 있었다. 원인을 찾는 데 시간이 오래 걸렸고, 결국 결선이 도면과 다르게 바뀐 것이 원인이었다. 교육에서 배운 I/O List 기반 결선(2-1)과 입출력장치 정상상태 확인(2-2)을 통해 입력 규격, NPN·PNP 출력 결선, LED 상태 확인 방법을 익혔다. 이를 적용해 결선 관리와 고장 점검 절차를 정리하였다.
- Ⅱ-1-1) 현상: 센서는 동작하지만 PLC에 입력 신호가 들어오지 않아 설비가 정지한다. 원인을 찾는 데 시간이 오래 걸려 생산 손실이 커진다.
- Ⅱ-1-2) 원인: ① 설비 개조 후 I/O List와 결선도를 갱신하지 않아 실제 결선과 도면이 다르다. ② NPN·PNP 센서 타입과 입력 모듈의 결선 방식을 혼동한다. ③ CPU·입출력 LED, 통신·모드 설정 등 정상상태 확인 순서가 정해져 있지 않다.
- Ⅱ-1-3) 개선 방안:
  1) 도면 갱신 규칙: 설비를 변경할 때 I/O List와 결선도를 함께 수정하고, 수정자와 날짜를 기록한다.
  2) 센서 교체 체크리스트: 센서를 교체할 때 NPN·PNP 타입, 정격 전압, 입력 모듈 규격을 확인하는 체크리스트를 사용한다.
  3) 점검 순서 표준화: 고장 시 PWR·RUN·ERR LED → 입출력 LED → 통신·모드 설정 → 결선 순서로 확인하는 점검 흐름도를 만들어 설비 옆에 비치한다.
  4) 모듈 취급 교육: 모듈 장착·분리 절차를 교육해 무리한 취급으로 인한 파손을 막는다.
- Ⅱ-1-4) 기대 효과: 결선 오류를 미리 막고, 고장이 나도 정해진 순서로 원인을 빠르게 찾을 수 있다. 숙련자가 없어도 기본 점검을 할 수 있어 대응 공백이 줄어든다. (정지 시간 단축 효과는 적용 후 고장 기록으로 확인 필요)
- Ⅱ-2. 실무와의 비교: 학습모듈에서는 매뉴얼의 입출력 규격과 I/O List를 기준으로 결선하고, LED와 모드 설정으로 정상상태를 확인하도록 한다. 우리 회사는 경험 많은 작업자의 감에 의존해 고장 위치를 찾는다. 이 때문에 그 작업자가 없으면 복구가 늦어진다. 배운 확인 순서를 흐름도로 표준화하면 누구나 같은 순서로 점검할 수 있다.
- Ⅲ-1. 소감: 입출력 규격과 결선 방식을 매뉴얼로 직접 확인해 보니, 현장에서 감으로 하던 작업에 근거가 생겼다. 특히 NPN과 PNP 출력의 차이를 직접 결선해 보면서 실수가 왜 생기는지 이해했다. LED 상태만 잘 읽어도 많은 정보를 얻을 수 있다는 점이 인상 깊었다. 배운 내용을 동료들과 나누고 싶다.
- Ⅲ-2. 향후 계획: 첫째, 담당 라인의 I/O List를 실제 결선과 대조해 최신 상태로 고치겠다. 둘째, 점검 흐름도와 센서 교체 체크리스트를 만들어 작업자와 공유하겠다. 셋째, 고장 기록을 정리해 반복되는 원인을 분석하겠다.

### 샘플 3 – 솔레노이드 밸브·공압 실린더 동작 불량
- 회사명: (예시) F사 – 포장 설비 운영
- 요약문 3. 문제해결 제안: 실린더 충격·밸브 소음 문제를 해결하기 위해 쿠션 조정, 밸브 점검 기준 수립, 회로 도면 정비, 실린더 선정 검토를 제안하였다.
- 요약문 4. 향후계획: 실린더 쿠션 점검과 밸브 점검 항목 추가를 진행하고, 회로 변경 이력을 도면과 함께 관리하도록 제안하겠다.
- Ⅰ-2. 문제해결 경험: 우리 회사 포장 설비는 공압 실린더가 끝단에서 세게 부딪혀 지그가 손상되거나, 솔레노이드 밸브에서 소음이 나고 응답이 늦어지는 문제가 있었다. 교육에서 배운 컨트롤 밸브·액추에이터 특성(4-1)을 통해 쉐이딩 링의 역할, AC 솔레노이드 코일 소손 원인, 실린더 쿠션 원리를 이해하게 되었다. 또한 구동기 회로구성과 조치(4-2)에서 수동·자동, 단속·연속 회로를 익혔다. 이를 바탕으로 구동기 점검과 회로 관리 방법을 정리하였다.
- Ⅱ-1-1) 현상: 실린더 끝단 충격으로 지그가 손상되고, 솔레노이드 밸브에서 소음과 동작 지연이 발생한다.
- Ⅱ-1-2) 원인: ① 실린더 쿠션이 조정되어 있지 않아 스트로크 끝에서 감속이 되지 않는다. ② 쉐이딩 링 이탈 등 밸브 상태를 점검하는 기준이 없다. ③ 수동·자동 회로가 도면과 다르게 변경되어 동작 확인이 어렵다.
- Ⅱ-1-3) 개선 방안:
  1) 쿠션 조정: 실린더 쿠션 니들을 조정하고, 하중과 속도가 큰 곳은 외부 쇼크 업소버 설치를 검토한다.
  2) 밸브 점검 기준: 솔레노이드 밸브의 소음·코일 온도·응답 상태를 점검 항목에 넣고, 이상 시 교체 기준을 정한다.
  3) 회로 도면 정비: 구동기 회로를 도면 기준으로 정비하고, 단속·연속 회로를 변경할 때는 도면을 함께 수정한다.
  4) 실린더 선정 검토: 용도에 맞는 실린더(단동·복동, 특수 실린더)와 설치 방법인지 확인한다.
- Ⅱ-1-4) 기대 효과: 충격과 소음으로 인한 부품 손상과 설비 정지를 줄이고 구동기 수명을 늘릴 수 있다. 회로 도면이 실제와 맞아 고장 시 원인 확인이 쉬워진다. (효과는 정비 이력으로 확인 필요)
- Ⅱ-2. 실무와의 비교: 학습모듈에서는 밸브와 실린더의 특성을 이해하고, 회로 도면을 기준으로 정상 동작을 감시하며 교정하도록 한다. 우리 회사는 이상이 생긴 뒤 부품을 교체하는 사후 정비 위주이다. 또 회로를 바꿔도 도면을 고치지 않아 다음 정비 때 혼란이 생긴다. 배운 특성을 점검 기준으로 만들면 예방 정비로 바꿀 수 있다.
- Ⅲ-1. 소감: 방향제어밸브 구성과 쿠션 원리를 실습하면서 현장에서 자주 보던 고장의 원인을 이론적으로 이해할 수 있었다. 특히 쉐이딩 링 하나가 소음과 관련된다는 점이 새로웠다. 회로를 직접 수정해 보니 도면 관리의 중요성도 알게 되었다. 앞으로 고장을 원인부터 생각하는 습관을 갖고 싶다.
- Ⅲ-2. 향후 계획: 첫째, 담당 설비의 실린더 쿠션 상태를 점검하고 조정하겠다. 둘째, 솔레노이드 밸브 점검 항목을 점검표에 추가하겠다. 셋째, 회로 변경 이력을 도면과 함께 관리하는 방법을 팀에 제안하겠다.

## [C] Ⅰ장 단원 작성 예시 (가공 방식 참고용, 보고서체·중간·중 기준)
> 문장을 그대로 복사하지 말고, 사용자의 문체·수준과 회사 상황에 맞게 다시 쓴다.

#### (1) 현장계측기 운영하기

**1-1. 공정변수와 온도 및 압력 검출방법**
- 가. 핵심 내용 정리: 공정변수는 온도·압력·농도·유속처럼 공정의 상태를 바꾸는 조건이며, 이를 정확히 재야 설비를 안정적으로 제어할 수 있다는 점을 이해하였다. 센서가 검출한 물리량은 그대로 쓰기 어려워 전송기를 거쳐 4~20mA, 1~5V 같은 표준 신호로 바뀐다는 원리를 정리하였다. 센서는 측정 대상에 따라 물리·역학·화학 센서로 나뉘고, 고를 때는 측정 범위·감도·응답속도·신뢰성을 함께 따져야 한다.
- 나. 실습 과정: 서미스터의 온도별 저항값을 측정하고, 온도 변화를 전압 출력으로 바꾸는 회로를 꾸며 출력의 직선성을 확인하였다. 로드셀과 차동증폭기로 하중에 따른 출력 전압 변화를 살펴보는 압력 센서 실험도 하였다.
- 다. 업무 적용: 설비의 온도·압력 표시값이 의심될 때 센서와 전송기 신호를 단계별로 확인하는 점검 순서로 활용할 수 있다.

**1-2. 유량, 액위 및 진동 검출 방법**
- 가. 핵심 내용 정리: 유량은 단위 시간에 흐르는 양이고, 밀도가 변하는 유체는 부피보다 질량으로 재는 것이 정확하다는 점을 배웠다. 액위는 플로트처럼 직접 재는 방법과 압력·전도율 등으로 간접적으로 재는 방법이 있으며, 진동은 압전 소자 등으로 검출할 수 있다.
- 나. 실습 과정: 결로 센서 회로로 액위가 검출되면 경보가 울리는지 확인하고, 압전형 진동센서에 신호를 넣어 출력이 가장 커지는 공진 주파수와 차단 주파수를 찾아보았다.
- 다. 업무 적용: 탱크 액위 경보나 설비 진동 이상 감지 장치를 점검할 때 검출 원리를 바탕으로 원인을 좁히는 데 활용할 수 있다.

#### (2) 입출력장치 운영하기

**2-1. 기본적인 운영 및 제어기기 결선**
- 가. 핵심 내용 정리: PLC 입출력장치는 매뉴얼의 입력·출력 규격을 지켜 결선해야 하며, 입력 전압·전류와 출력 부하 조건을 벗어나면 오동작이나 소자 손상이 생긴다는 점을 이해하였다. I/O List는 어떤 현장기기가 어느 단자에 연결되는지를 정리한 기준 문서로, 결선과 고장 점검의 출발점이 된다.
- 나. 실습 과정: DC 입력부에 센서 같은 외부기기를 접속하고, NPN·PNP 트랜지스터 출력 회로를 각각 구성해 결선 방식의 차이를 확인하였다.
- 다. 업무 적용: 설비를 개조하거나 센서를 교체할 때 I/O List와 결선을 함께 확인하는 절차로 활용하면 결선 오류를 줄일 수 있다.

**2-2. 기본적인 구성과 정상상태의 이해**
- 가. 핵심 내용 정리: 입출력장치는 CPU 상태 LED, 입출력 LED, 통신 단자, 모드 설정 스위치 등으로 구성되며, 각 표시를 읽으면 장치가 정상인지 빠르게 판단할 수 있다는 점을 배웠다. 운전 모드에는 RUN, STOP, PAUSE, REMOTE가 있어 상황에 맞게 설정해야 한다.
- 나. 실습 과정: PWR·RUN·ERR LED로 CPU 상태를 확인하고 입출력 단자와 통신·모드 설정을 점검하였다. 모듈을 정해진 순서로 장착하고 분리하는 실습도 하였다.
- 다. 업무 적용: 설비 정지 시 LED 상태부터 차례대로 확인하는 점검 흐름을 만들면 고장 원인을 빠르게 찾는 데 활용할 수 있다.

#### (3) 전송기 운영하기

**3-1. 전송기의 동작과 검사**
- 가. 핵심 내용 정리: 데이터 전송기는 현장의 아날로그·디지털 신호를 컴퓨터로 보내 기록하고 분석하게 해 주는 장치라는 점을 이해하였다. 신호선 연결 방법과 채널 구성을 매뉴얼대로 지켜야 정확한 데이터를 얻을 수 있다.
- 나. 실습 과정: 전송기 소프트웨어를 설치하고 장치를 연결한 뒤, 입력 신호가 실시간으로 표시·전송되는지 확인해 동작 상태를 검사하였다.
- 다. 업무 적용: 설비 데이터를 수집해 이상 징후를 기록하는 데 전송기를 활용하면 사후 대응 대신 예방 점검에 도움이 된다.

**3-2. 전송기 회로구성과 조치**
- 가. 핵심 내용 정리: 전송기 회로는 핀 구성과 전원 연결을 정확히 지켜야 하며, 커넥터를 잘못 동시에 연결하면 데이터선이 합선될 수 있다는 점을 배웠다. USB 전원은 공급 가능한 전류가 작으므로 모터처럼 큰 전류가 필요한 부하에는 외부 전원을 따로 써야 한다.
- 나. 실습 과정: LED 표시로 다운로드 중·완료·연결 오류 상태를 구분해 보고, USB 전원과 외부 전원을 분리하는 절차를 실습하였다.
- 다. 업무 적용: 전송 장비의 LED 상태와 전원 구성을 점검 항목으로 정리하면 통신 불량의 원인을 빠르게 찾는 데 활용할 수 있다.

#### (4) 구동기 운영하기

**4-1. 구동기의 동작과 활용**
- 가. 핵심 내용 정리: 솔레노이드 밸브는 코일 전류로 생기는 흡인력으로 동작하며, AC 전원은 스트로크가 큰 상태로 오래 통전하면 코일이 손상될 수 있다는 점을 이해하였다. 쉐이딩 링은 AC 솔레노이드의 소음을 막는 부품이고, 절연 등급에 따라 허용 온도 상승이 다르다. 공압 실린더는 단동과 복동, 여러 특수 실린더가 있어 용도에 맞게 골라야 한다.
- 나. 실습 과정: 용도에 맞는 방향제어밸브를 구성해 보고, 실린더가 스트로크 끝에서 충격을 줄이는 쿠션의 원리를 확인하였다.
- 다. 업무 적용: 밸브 소음, 코일 발열, 실린더 끝단 충격을 점검 항목으로 넣으면 구동기 고장을 미리 막는 데 활용할 수 있다.

**4-2. 구동기 회로구성과 조치**
- 가. 핵심 내용 정리: 구동기 회로는 수동과 자동을 선택할 수 있어야 하며, 자동에는 한 번만 동작하는 단속과 계속 동작하는 연속 방식이 있다는 점을 배웠다. 두 방식이 모두 필요하면 조건을 병렬로 연결해 구성한다.
- 나. 실습 과정: 자기유지 회로를 이용한 자동 연속 회로를 확인하고, 단속·연속 스위치를 병렬로 연결하는 회로로 수정해 동작을 확인하였다.
- 다. 업무 적용: 회로를 변경할 때 도면을 함께 수정하고 수동·자동 동작을 모두 확인하는 절차로 활용할 수 있다.
