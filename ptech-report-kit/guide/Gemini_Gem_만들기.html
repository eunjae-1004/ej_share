Gemini Gem로 최종보고서 도우미 만들기

Gemini Gem에 지침과 소스를 넣어 두면, 완성 보고서를 Canvas에 만들어 Google 문서로 내보낸 뒤 PDF로 저장합니다.

Canvas → Google 문서 → PDF 저장 · 사진은 문서에서 직접 넣기

준비물

강사가 배포한 키트(또는 GitHub에서 내려받은 ZIP)의 「Gemini」 폴더에 있는 파일입니다. Google 계정이면 무료로 Gem을 만들 수 있습니다. Gem 만들기·수정은 PC 웹(gemini.google.com)에서만 되고, 휴대폰 앱에서는 만든 Gem으로 대화만 할 수 있습니다.

Gemini는 PDF 파일을 직접 만들지 못합니다. 보고서는 Canvas에 완성되고, Google 문서로 내보낸 뒤 PDF로 저장합니다.

① 만들기 (처음 한 번)

  1. 로그인PC에서 gemini.google.com에 접속해 Google 계정으로 로그인합니다.
  2. 새 Gem왼쪽 메뉴에서 Gem 탐색(Explore Gems) → 새 Gem(New Gem)을 누릅니다.
  3. 이름 입력이름(Name)에 P-Tech 최종보고서를 입력합니다.
  4. 지침 넣기요청사항(Instructions) 칸에 아래 [지침 문구]를 붙여 넣습니다.
  5. 소스 올리기지식(Knowledge)의 파일 추가로 소스 파일 5개를 올립니다.
  6. 저장오른쪽 미리보기는 저장되지 않습니다. 반드시 저장(Save)을 누릅니다.

② 보고서 작성 (매번)

  1. 채팅 시작Gem 목록에서 P-Tech 최종보고서를 열고 시작이라고 입력합니다. 안내문과 입력양식이 나옵니다.
  2. 입력양식 채우기입력양식을 복사해 붙여 넣고 채웁니다. 사진이 있으면 함께 보내면 넣을 자리를 정해 줍니다.
  3. 초안 확인초안을 읽고 고칠 곳을 말로 요청합니다.
  4. 보고서 만들기보고서로 만들어 주세요라고 입력하면 Canvas(캔버스)에 완성 보고서가 만들어집니다.
  5. Google 문서로 내보내기캔버스 오른쪽 위 공유 및 내보내기 → Docs로 내보내기를 누릅니다.
  6. PDF 저장Google 문서의 [그림 넣을 자리]에 삽입 → 이미지로 사진을 넣고, 파일 → 다운로드 → PDF 문서로 저장합니다.

지침 문구

아래 내용을 그대로 복사해 요청사항(Instructions) 칸에 붙여 넣으세요.

너는 원주폴리텍대학 P-Tech 학습자의 「[서식5] 최종보고서」 작성 도우미다.

1. 첫 메시지에는 지식 파일 「소스1_작성규칙_Gemini.md」의 [시작 안내문]과 입력양식을 보여 준다.
2. 소스1(작성 절차·원칙·보고서 문서 만들기·처리가 안 될 때 안내문), 소스2(작성 스타일), 소스3(업종별 예시문)을 반드시 그대로 따른다.
3. 교과목 자료는 학습자가 고른 과목만 쓴다: 자재관리 → 소스4, 현장제어 → 소스5.
4. 초안을 먼저 보여 주고, "보고서로 만들어 주세요"라는 승인 후에만 Canvas에 완성 문서를 만든다.
5. 학습자가 말하지 않은 수치·회사 사실은 지어내지 않는다.
6. 학습자는 AI가 처음인 재직자다. 쉬운 말로 짧게 안내하고, 기술 설명은 하지 않는다.

처리가 안 될 때

아래 상황이 생기면 도우미가 안내문을 보여 줍니다. 안내대로 하면 됩니다.
