ChatGPT 프로젝트로 최종보고서 도우미 만들기

ChatGPT 프로젝트에 지침과 통합 소스 1개, PDF 생성 코드를 넣어 둡니다. 한글 PDF가 안 되면 글꼴 파일 첨부나 Word 파일로 대신합니다.

PDF 생성(한글 글꼴 필요할 수 있음) · 사진 자동 배치

키트 내려받기: https://github.com/eunjae-1004/ej_share/tree/main/ptech-report-kit

준비물

강사가 배포한 키트(또는 GitHub에서 내려받은 ZIP)의 「ChatGPT」 폴더에 있는 파일입니다. chatgpt.com 무료 계정으로 프로젝트를 만들 수 있습니다. 무료 계정은 프로젝트당 파일 수와 하루 업로드 수가 제한된다는 자료가 있어(확인 필요), 소스를 파일 1개로 합쳤습니다.

첨부학습모듈(참고용) 폴더필요할 때만 채팅에 첨부(선택) – 무료 계정은 업로드 수 제한 주의
ChatGPT 작업 환경에는 한글 글꼴이 없는 경우가 많아 PDF 한글이 깨질 수 있습니다. 이때 안내문이 나오며, 글꼴 파일(NanumGothic.ttf)을 첨부하거나 Word 파일로 받으면 됩니다.

① 만들기 (처음 한 번)

  1. 로그인chatgpt.com에 접속해 로그인합니다. 계정이 없으면 무료로 가입합니다.
  2. 새 프로젝트왼쪽 사이드바에서 새 프로젝트를 누릅니다.
  3. 이름 입력이름에 P-Tech 최종보고서를 입력하고 프로젝트를 만듭니다.
  4. 지침 넣기프로젝트 화면의 지침(Instructions) 추가를 누르고, 아래 [지침 문구]를 붙여 넣은 뒤 저장합니다.
  5. 파일 올리기파일 추가로 소스_통합_ChatGPT.md와 첨부_PDF생성코드.txt 2개를 올립니다.
  6. 글꼴 준비네이버 나눔글꼴에서 NanumGothic.ttf를 미리 내려받아 둡니다. 한글이 깨진다는 안내가 나올 때만 첨부합니다.

② 보고서 작성 (매번)

  1. 채팅 시작프로젝트 안에서 새 채팅을 열고 시작이라고 입력합니다. 안내문과 입력양식이 나옵니다.
  2. 입력양식 채우기입력양식을 복사해 채팅창에 붙여 넣고 채웁니다. 모르는 칸은 비워 두면 업종별 예시문으로 작성됩니다.
  3. 사진 첨부(선택)사진이 있으면 +로 첨부합니다. 무료 계정은 하루 업로드 수가 적으니 1~2장을 권합니다.
  4. 초안 확인초안을 읽고 고칠 곳을 말로 요청합니다. 예: "설명문체로", "수준 상으로"
  5. PDF 받기PDF로 만들어 주세요라고 입력하고, 내려받기 링크로 PDF를 받습니다. 한글 글꼴 안내가 나오면 아래 표대로 진행합니다.

지침 문구

아래 내용을 그대로 복사해 지침 칸에 붙여 넣으세요.

너는 원주폴리텍대학 P-Tech 「[서식5] 최종보고서」 작성 도우미다.

1. 첫 메시지에는 프로젝트 파일 「소스_통합_ChatGPT.md」의 [시작 안내문]과 입력양식을 보여 준다.
2. 「소스_통합_ChatGPT.md」의 작성 절차·작성 스타일·업종별 예시문·작성 원칙·PDF 생성 방법·처리가 안 될 때 안내문을 반드시 그대로 따른다.
3. 교과목 자료는 사용자가 고른 과목만 쓴다: 자재관리 → [소스4], 현장제어 → [소스5].
4. 초안을 먼저 보여 주고, "PDF로 만들어 주세요"라는 승인 후에만 프로젝트 파일 「첨부_PDF생성코드.txt」로 PDF를 만든다.
5. 사용자가 말하지 않은 수치·회사 사실은 지어내지 않는다.
6. 사용자는 AI가 처음인 재직자다. 쉬운 말로 짧게 안내하고, 코드나 기술 설명은 하지 않는다.

처리가 안 될 때

아래 상황이 생기면 도우미가 안내문을 보여 줍니다. 안내대로 하면 됩니다.

상황나오는 안내사용자가 할 일
코드 파일을 찾지 못할 때「첨부_PDF생성코드.txt」를 첨부해 달라는 안내+ 버튼으로 파일 첨부 후 다시 요청
한글 글꼴이 없을 때(가장 흔함)글꼴 첨부 또는 Word 선택 안내NanumGothic.ttf 첨부 후 "PDF로 다시 만들어 주세요", 또는 "Word로 만들어 주세요"
Word로 대체된 경우Word 파일과 PDF 저장 방법 안내Word에서 파일 → 다른 이름으로 저장 → PDF
사진이 열리지 않을 때JPG로 다시 첨부하라는 안내JPG로 저장(또는 캡처) 후 재첨부, 또는 "사진 빼고 만들어 주세요"
파일을 더 올릴 수 없을 때무료 계정 업로드 한도 안내사진을 줄이거나 다음 날 다시 시도(사진 없이도 작성 가능)
