Claude 프로젝트로 최종보고서 도우미 만들기

Claude 프로젝트에 지침과 소스를 넣어 두면, 사용자는 입력양식만 채워 [서식5] 최종보고서 PDF를 바로 받을 수 있습니다.

PDF 자동 생성 · 사진 자동 배치

키트 내려받기: https://github.com/eunjae-1004/ej_share/tree/main/ptech-report-kit

준비물

강사가 배포한 키트(또는 GitHub에서 내려받은 ZIP)의 「Claude」 폴더에 있는 파일입니다. claude.ai 무료 계정으로 만들 수 있습니다. 무료 계정은 프로젝트를 최대 5개까지 만들 수 있고, 사용량 한도가 있습니다.

① 만들기 (처음 한 번)

  1. 로그인claude.ai에 접속해 로그인합니다. 계정이 없으면 Google 계정이나 이메일로 무료 가입합니다.
  2. 새 프로젝트왼쪽 메뉴에서 프로젝트(Projects)를 누르고, 오른쪽 위 + 새 프로젝트를 누릅니다.
  3. 이름 입력이름에 P-Tech 최종보고서를 입력하고 프로젝트를 만듭니다.
  4. 지침 넣기프로젝트 지침 설정(Set project instructions)을 누르고, 아래 [지침 문구]를 복사해 붙여 넣은 뒤 저장합니다.
  5. 소스 올리기오른쪽 지식(파일) 영역의 + 버튼으로 소스1~소스5 파일 5개를 올립니다.
  6. 기능 확인PDF를 만들려면 파일 생성 기능이 켜져 있어야 합니다. 기본으로 켜져 있지만, 안 되면 설정 → 기능에서 코드 실행 및 파일 생성을 켭니다.

② 보고서 작성 (매번)

  1. 채팅 시작프로젝트 안에서 새 채팅을 열고 시작이라고 입력합니다. 안내문과 입력양식이 나옵니다.
  2. 입력양식 채우기입력양식의 복사 버튼을 눌러 채팅창에 붙여 넣고 채웁니다. 모르는 칸은 비워 두면 업종별 예시문으로 작성됩니다.
  3. 파일 첨부+ 버튼으로 첨부_PDF생성코드.txt와 (있으면) 실습·현장 사진 최대 4장을 첨부하고 보냅니다.
  4. 초안 확인초안을 읽고 고칠 곳을 말로 요청합니다. 예: "음슴체로", "더 길게", "B 사례로 바꿔 주세요"
  5. PDF 받기PDF로 만들어 주세요라고 입력하고, 만들어진 PDF를 내려받아 확인한 뒤 제출합니다.

지침 문구

아래 내용을 그대로 복사해 지침 칸에 붙여 넣으세요.

너는 원주폴리텍대학 P-Tech 「[서식5] 최종보고서」 작성 도우미다.

1. 첫 메시지에는 「소스1_작성규칙.md」의 [시작 안내문]과 입력양식을 보여 준다.
2. 소스1(작성 절차·원칙·PDF 생성), 소스2(작성 스타일), 소스3(업종별 예시문)을 반드시 그대로 따른다.
3. 교과목 자료는 사용자가 고른 과목만 쓴다: 자재관리 → 소스4, 현장제어 → 소스5.
4. 초안을 먼저 보여 주고, "PDF로 만들어 주세요"라는 승인 후에만 「첨부_PDF생성코드.txt」로 PDF를 만든다.
5. 사용자가 말하지 않은 수치·회사 사실은 지어내지 않는다.
6. 사용자는 AI가 처음인 재직자다. 쉬운 말로 짧게 안내하고, 코드나 기술 설명은 하지 않는다.

처리가 안 될 때

아래 상황이 생기면 도우미가 안내문을 보여 줍니다. 안내대로 하면 됩니다.

상황나오는 안내사용자가 할 일
코드 파일을 첨부하지 않았을 때「첨부_PDF생성코드.txt」를 첨부해 달라는 안내+ 버튼으로 파일 첨부 후 "PDF로 만들어 주세요" 다시 입력
PDF에 한글 글꼴을 넣지 못했을 때글꼴 파일 첨부 또는 Word 대체 안내NanumGothic.ttf 첨부, 또는 "Word로 만들어 주세요" 입력
Word로 대체된 경우Word 파일과 PDF 저장 방법 안내Word에서 파일 → 다른 이름으로 저장 → PDF
사진이 열리지 않을 때해당 사진을 JPG로 다시 첨부하라는 안내JPG로 저장(또는 캡처) 후 재첨부, 또는 "사진 빼고 만들어 주세요"
파일 생성 기능이 꺼져 있을 때설정에서 기능을 켜라는 안내설정 → 기능 → 코드 실행 및 파일 생성 켜기
사용량 한도 메시지가 나올 때Claude 화면의 한도 안내(시스템 메시지)표시된 시간 이후 같은 채팅에서 이어서 진행
