ChatGPT 플러그인로 최종보고서 도우미 만들기

ChatGPT의 Plugin Creator에 파일 3개를 첨부하고 제작 요청문을 보내면 'P-Tech 최종보고서 작성기' 플러그인이 만들어집니다. 이후 새 대화에서 @로 불러 씁니다.

플러그인으로 등록 · PDF 생성(한글 글꼴 없으면 글꼴 첨부 또는 Word로 대체)

키트 내려받기: https://github.com/eunjae-1004/ej_share/tree/main/ptech-report-kit

준비물

강사가 배포한 키트(또는 GitHub에서 내려받은 ZIP)의 「ChatGPT」 폴더에 있는 파일입니다. 플러그인 만들기는 ChatGPT 웹에서 Plugin Creator를 쓸 수 있는 계정에서만 됩니다. 요금제별 제공 여부는 공식 안내에 명시되어 있지 않아, 먼저 @ 입력 시 Plugin Creator가 보이는지 확인하세요.

첨부지침_ChatGPT.txtPlugin Creator 대화에 첨부 – 최우선 지침
첨부소스_통합_ChatGPT.mdPlugin Creator 대화에 첨부 – 참고자료
첨부첨부_PDF생성코드.txtPlugin Creator 대화에 첨부 – PDF 생성 코드
지침플러그인_제작요청문.txtPlugin Creator에 보낼 요청문(아래 복사 버튼과 같음)
첨부NanumGothic.ttf한글이 깨질 때만 보고서 대화에 첨부(미리 내려받아 두기)
첨부학습모듈(참고용) 폴더필요할 때만 보고서 대화에 첨부(선택)
ChatGPT 작업 환경에는 한글 글꼴이 없는 경우가 많아 PDF 한글이 깨질 수 있습니다. 이때 안내문이 나오며, 글꼴 파일(NanumGothic.ttf)을 첨부하거나 Word 파일로 받으면 됩니다.

① 만들기 (처음 한 번)

  1. 준비「ChatGPT」 폴더의 지침_ChatGPT.txt, 소스_통합_ChatGPT.md, 첨부_PDF생성코드.txt 3개와 플러그인_제작요청문.txt를 준비합니다.
  2. Plugin Creator 선택chatgpt.com에서 새 대화를 열고 입력창에 @를 입력한 뒤 목록에서 Plugin Creator를 선택합니다.
  3. 파일 3개 첨부메시지 입력창 옆 첨부(+) 버튼으로 파일 3개를 첨부합니다. 별도의 파일 등록 화면을 찾는 것이 아니라, 이 제작 대화에 파일을 첨부하는 방식입니다.
  4. 제작 요청아래 [제작 요청문]을 복사해 붙여 넣고 보냅니다. Plugin Creator가 질문하면 답하고, 이름·설명·지침·포함 파일을 검토합니다.
  5. 등록 결과 확인생성된 플러그인 링크와 포함 자료(파일 3개)를 확인합니다. 설치 안내가 나오면 설치합니다.
  6. 새 대화에서 시험새 대화에서 @로 만든 플러그인을 선택하고 시작을 입력합니다. 설명과 복사용 입력양식이 분리되는지, 기본정보·과목이 정확히 반영되는지, 초안 수정과 PDF 출력까지 되는지 확인합니다.

② 보고서 작성 (매번)

  1. 플러그인 부르기새 대화 입력창에 @를 입력하고 P-Tech 최종보고서 작성기를 선택한 뒤 시작이라고 입력합니다.
  2. 입력양식 채우기안내문 아래 코드블록의 입력양식을 복사해 붙여 넣고 채웁니다. 성명과 교과목은 필수, 나머지는 비워 둬도 됩니다.
  3. 사진 첨부(선택)사진이 있으면 +로 첨부합니다(최대 4장). 얼굴이나 회사 기밀이 보이는 사진은 피합니다.
  4. 초안 확인초안을 읽고 고칠 곳을 말로 요청합니다. 예: "설명문체로", "수준 상으로"
  5. PDF 받기PDF로 만들어 주세요라고 입력하고 내려받기 링크로 PDF를 받습니다. 한글 글꼴 안내가 나오면 아래 표대로 진행합니다.

제작 요청문

Plugin Creator 대화에 파일 3개를 첨부한 뒤, 아래 요청문을 그대로 복사해 보내세요.

첨부한 파일 3개를 포함해
'P-Tech 최종보고서 작성기' 플러그인을 만들어줘.
지침_ChatGPT.txt를 최우선으로 적용하고,
소스_통합_ChatGPT.md는 참고자료로,
첨부_PDF생성코드.txt는 PDF 생성용 코드로 포함해줘.
초안을 먼저 보여주고 사용자가 'PDF로 만들어 주세요'라고
요청한 후에만 PDF를 생성하도록 해줘.
등록 후 실제 작동 여부를 확인하고,
아직 확인되지 않은 기능은 구분해서 알려줘.

처리가 안 될 때

아래 상황이 생기면 도우미가 안내문을 보여 줍니다. 안내대로 하면 됩니다.

상황나오는 안내사용자가 할 일
@를 눌러도 Plugin Creator가 없을 때(만들기 단계 문제)계정·워크스페이스에서 플러그인 만들기가 꺼져 있을 수 있음 – 관리자 확인 또는 Claude·Gemini 방식 사용
PDF 코드 파일을 찾지 못할 때「첨부_PDF생성코드.txt」를 첨부해 달라는 안내보고서 대화에 + 버튼으로 코드 파일 첨부 후 다시 요청
한글 글꼴이 없을 때(가장 흔함)글꼴 첨부 또는 Word 선택 안내NanumGothic.ttf 첨부 후 "PDF로 다시 만들어 주세요", 또는 "Word로 만들어 주세요"
Word로 대체된 경우Word 파일과 PDF 저장 방법 안내Word에서 파일 → 다른 이름으로 저장 → PDF
사진이 열리지 않을 때JPG로 다시 첨부하라는 안내JPG로 저장(또는 캡처) 후 재첨부, 또는 "사진 빼고 만들어 주세요"
파일을 더 올릴 수 없을 때업로드 한도 안내사진을 줄이거나 다음 날 다시 시도(사진 없이도 작성 가능)
